## M05: 关卡分配引擎 (LevelAssignmentEngine)

### 5.1 模块定位与职责

| 属性 | 说明 |
|------|------|
| **职责范围** | 将142个原始关卡分配到9层×每层9格的地图中，含BOSS改造逻辑 |
| **输入** | 关卡数据库(142关)、层级配置(M02)、当前种子值 |
| **输出** | 每层的 `levelId → cellId` 映射表 + BOSS配置 |
| **依赖** | M01(types), M02(constants), M03(utils) |
| **被依赖** | M04(map data), M06(cell state), M11(progress) |
| **技术栈** | TypeScript (纯逻辑，无UI) |

### 5.2 核心数据结构

```typescript
class LevelAssignmentEngine {
  private levelPools: Map<number, LevelPool>;
  private rng: () => number;

  constructor(seed?: number);

   * 执行单层分配

   * 执行全塔分配（一次性分配9层）

  assignAllLayers(
    layerConfigs: Array<{
      layerNumber: number;
      battleCellIds: string[];
      bossCellId: string;

  ): TowerAssignmentResult;

  /**
   * BOSS关卡改造

  getSparePool(layerNumber: number): string[];

  validateAssignment(result: TowerAssignmentResult): AssignmentValidationResult;

  /** 重新洗牌（使用新种子） */
  reshuffle(newSeed?: number): void;
}
```

### 5.4 核心算法流程

```
┌─────────────────────────────────────┐
│       assignLayer(layer, cells)      │
└─────────────────┬───────────────────┘
                  │
                  ▼
┌─────────────────────────────────────┐
│ 1. 获取该层主题对应的关卡池           │
│    pool = pools[layer.themeId]      │
│    需要: len(battleCellIds) 个关卡   │
└─────────────────┬───────────────────┘
                  │
                  ▼
┌─────────────────────────────────────┐
│ 2. 检查池中可用数量是否充足            │
│    if available < needed:           │
│      从备用池补充 或 报错            │
└─────────────────┬───────────────────┘
                  │
                  ▼
┌─────────────────────────────────────┐
│ 3. 加权随机抽取（避免重复）            │
│    使用 pickN(pool.available, n)     │
│    打乱顺序后依次分配到battleCellIds  │
└─────────────────┬───────────────────┘
                  │
                  ▼
┌─────────────────────────────────────┐
│ 4. BOSS改造                          │
│    baseId = 从池中取最强的一关         │
│    bossConfig = enhanceBossLevel()   │
│    绑定到 bossCellId                 │
└─────────────────┬───────────────────┘
                  │
                  ▼
┌─────────────────────────────────────┐
│ 5. 更新池状态 & 返回结果              │
│    pool.assigned += selected         │
│    pool.spare += remaining           │
│    return LayerAssignmentResult      │
└─────────────────────────────────────┘
```

```typescript
// ====== 状态转换请求 ======
interface StateTransitionRequest {
  cellId: string;
  targetState: CellState;
  reason: TransitionReason;
  force?: boolean;               // 是否强制转换（跳过规则校验）
  metadata?: Record<string, unknown>;
}

type TransitionReason =
  | 'player_enter'               // 玩家进入
  | 'player_exit'                // 玩家离开
  | 'battle_victory'             // 战斗胜利
  | 'battle_defeat'              // 战斗失败
  | 'function_completed'         // 功能格完成
  | 'neighbor_unlocked'          // 邻居解锁连锁
  | 'layer_start'                // 层开始初始化
  | 'zone_effect'                // 区域效果影响
  | 'admin_force';               // 管理员强制

// ====== 状态转换结果 ======
interface StateTransitionResult {
  success: boolean;
  cellId: string;
  previousState: CellState;
  newState: CellState;
  reason: TransitionReason;
  sideEffects: SideEffect[];
  errorMessage?: string;
}

  targetCells?: string[];
  data?: unknown;
}
```

### 6.4 状态机规则矩阵

```
当前状态 ──[触发条件]──→ 目标状态
═════════════════════════════════════
locked  ──[邻居被访问/层开始]──→ unlocked
locked  ──[前置条件满足]──────→ pending

unlocked ──[玩家进入]─────────→ current
pending  ──[条件达成]─────────→ unlocked

current  ──[玩家离开/触发后]──→ visited
visited  ──[战斗胜利/功能完成]──→ completed
visited  ──[战斗失败]─────────→ unlocked (允许重试)

completed ──(终态，不可再变)
```

### 6.5 类型分发器

```typescript
/**
 * 根据格子类型分发到不同的处理器
 * 本模块只负责分发，具体执行委托给 M09
 */
class CellTypeDispatcher {
  dispatch(
    cell: GameCell,
    context: CellTriggerContext
  ): CellActionResult | null {

    switch (cell.type) {
      case 'battle':
        return this.handleBattle(cell as BattleCell, context);
      case 'chance':
        return this.handleChance(cell as ChanceCell, context);
      case 'bookstore':
        return this.handleBookstore(cell as BookstoreCell, context);
      case 'skill':
        return this.handleSkill(cell as SkillCell, context);
      case 'boss':
        return this.handleBoss(cell as BossCell, context);
      case 'end':
        return this.handleEnd(cell as EndCell, context);
      default:
        return null;
    }
  }

  // 各类型的预处理逻辑（不包含实际执行）
  private handleBattle(cell: BattleCell, ctx: CellTriggerContext): PreActionInfo;
  private handleChance(cell: ChanceCell, ctx: CellTriggerContext): PreActionInfo;
  private handleBookstore(cell: BookstoreCell, ctx: CellTriggerContext): PreActionInfo;
  private handleSkill(cell: SkillCell, ctx: CellTriggerContext): PreActionInfo;
  private handleBoss(cell: BossCell, ctx: CellTriggerContext): PreActionInfo;
  private handleEnd(cell: EndCell, ctx: CellTriggerContext): PreActionInfo;
}

interface PreActionInfo {
  actionType: CellType;
  requiredInputs: Record<string, unknown>;
  expectedOutputs: string[];
  estimatedDurationMs: number;
  canExecute: boolean;
  blockReason?: string;
}
```

### 7.4 效果处理优先级与叠加规则

```
优先级从高到低:
  ① I (反转) - 全局效果，立即处理，优先级最高
  ② D (危险) - 资源损失，高优先级
  ③ P (休整) - 跳过回合，中等优先级
  ④ W (虚弱) - 骰子-1，低优先级
  ⑤ S (加速) - 骰子+1/额外投掷，低优先级
  ⑥ N (知识) - 获得书籍，最低优先级（奖励性质）

叠加规则:
- W 和 S 可叠加（最终修改量 = sum of all modifiers）
- D 每次独立计算（不叠加，每次独立扣减）
- N 可无限叠加（获得多本书）
- I 有全局上限 (globalMaxTriggers=3)
- P 不叠加（多次踩中只生效一次/次）
```

### 8.4 骰子系统

```typescript
class DiceSystem {
  private sides: number;
  private modifiers: DiceModifierSource[];

  constructor(sides: number = MOVEMENT_CONFIG.DICE_SIDES);

  /** 投掷骰子 */
  roll(rng?: () => number): number;

  /** 应用修改器 */
  applyModifiers(rawValue: number, modifiers: DiceModifierApplied[]): DiceRollResult {
    let modified = rawValue;
    const applied: DiceModifierApplied[] = [];

    for (const mod of modifiers) {
      modified += mod.delta;
      applied.push(mod);
    }

    // 保底值约束
    modified = Math.max(MOVEMENT_CONFIG.MIN_DICE_VALUE, modified);
    modified = Math.min(MOVEMENT_CONFIG.MAX_DICE_VALUE, modified);

    return {
      rawValue,
      modifiedValue: modified,
      modifiers: applied,
    };
  }

  /** S区额外投掷（取最优） */
  rollWithBonus(rng?: () => number): DiceRollResult {
    const first = this.roll(rng);
    const second = this.roll(rng);
    return {
      rawValue: Math.max(first, second),
      modifiedValue: Math.max(first, second),
      modifiers: [{
        source: 'zone_S',
        delta: 0,
        description: `加速区：额外投掷，取${Math.max(first, second)}点`,
      }],
    };
  }
}
```

### 8.5 路径搜索算法（BFS）

```typescript
/**
 * BFS寻路：找到从当前位置到所有可达格子的最短路径
 * 约束条件：
 * 1. 只能沿 paths 定义的方向移动
 * 2. 总距离 ≤ diceValue
 * 3. 不能经过 locked 状态的格子
 * 4. 可以选择经过/绕过危险区域
 */
function findReachableCells(
  startCellId: string,
  maxDistance: number,
  layerData: TowerLayerData,
  cellStates: Map<string, CellState>
): ReachableCell[] {

  const visited = new Set<string>();
  const queue: Array<{ cellId: string; distance: number; path: string[] }> = [
    { cellId: startCellId, distance: 0, path: [startCellId] }
  ];
  const results: ReachableCell[] = [];

  while (queue.length > 0) {
    const { cellId, distance, path } = queue.shift()!;

    if (visited.has(cellId)) continue;
    visited.add(cellId);

    // 跳过起点自身
    if (distance > 0) {
      const cell = layerData.cellIndex[cellId];
      results.push({
        cell,
        distance,
        path: path.map(id => layerData.cellIndex[id].coordinate),
        isOptimal: true,
        zoneWarnings: cell.zone ? [cell.zone] : [],
      });
    }

    // 距离已达上限则不再扩展
    if (distance >= maxDistance) continue;

    // 获取邻居
    const neighbors = layerData.adjacencyList[cellId] || [];
    for (const neighborId of neighbors) {
      if (visited.has(neighborId)) continue;
      const neighborState = cellStates.get(neighborId);
      if (neighborState === 'locked') continue;

      queue.push({
        cellId: neighborId,
        distance: distance + 1,
        path: [...path, neighborId],
      });
    }
  }

  return results.sort((a, b) => a.distance - b.distance);
}
```

```typescript
/**
 * useMovement Hook - 提供给React组件使用的移动控制接口
 */
function useMovement(
  layerData: TowerLayerData | null,
  zoneManager: ZoneEffectManager | null,
  cellStateMachine: CellStateMachine | null
): MovementHookReturn {

  const [engine] = useState(() => new MovementEngine(zoneManager!));
  const [diceResult, setDiceResult] = useState<DiceRollResult | null>(null);
  const [moveOptions, setMoveOptions] = useState<MoveOption[]>([]);
  const [isMoving, setIsMoving] = useState(false);
  const [currentPos, setCurrentPos] = useState<Coordinate2D>([0, 0]);

  useEffect(() => {
    if (layerData) engine.loadLayerData(layerData);
  }, [layerData]);

  const rollDice = useCallback(() => {
    const result = engine.rollDice();
    setDiceResult(result);
    const options = engine.getMoveOptions(result.modifiedValue);
    setMoveOptions(options);
    return result;
  }, [engine]);

  const moveTo = useCallback(async (targetCellId: string) => {
    setIsMoving(true);
    try {
      const result = await engine.executeMove(targetCellId);
      setCurrentPos(engine.getCurrentPosition().coord);
      return result;
    } finally {
      setIsMoving(false);
    }
  }, [engine]);

  return {
    diceResult,
    moveOptions,
    isMoving,
    currentPos,
    rollDice,
    moveTo,
    canMove: engine.canMove(),
    moveHistory: engine.getMoveHistory(),
    cancelMove: () => engine.cancelMove(),
  };
}

interface MovementHookReturn {
  diceResult: DiceRollResult | null;
  moveOptions: MoveOption[];
  isMoving: boolean;
  currentPos: Coordinate2D;
  rollDice: () => DiceRollResult;
  moveTo: (targetCellId: string) => Promise<MovementResult>;
  canMove: boolean;
  moveHistory: ReadonlyArray<MovementRecord>;
  cancelMove: () => boolean;
}
```
