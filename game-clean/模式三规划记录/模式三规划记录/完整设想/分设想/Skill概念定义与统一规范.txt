Skill概念定义与统一规范

【说明】本文档是爬塔模式中Skill（技能）概念的权威定义文件，所有涉及Skill的设计文档均以本文件为准。如与其他文档存在冲突，以本文件为准。

========================================
一、Skill概念定义
========================================

1.名称与术语
  - 中文术语：技能
  - 英文术语：Skill
  - 代码标识：skill
  - 与关卡模式"角色技能"的区分：关卡模式中的"角色技能"是角色固有的专属能力（如防御方角色的"坚盾直觉"），与角色绑定，不可更换；爬塔模式中的"技能/Skill"是通过地图格子获取的通用能力，可替换、可管理，与角色无关。两者虽同名但属于不同系统，在上下文中通过"角色技能"和"爬塔技能"区分

2.核心定位
  - Skill是爬塔模式中通过地图交互获取的被动/主动能力
  - Skill独立于卡牌系统（卡牌是战斗内出牌使用的），独立于数据包系统（数据包是不可管理的被动遗物）
  - Skill的核心特征：可管理（装备/替换/仓库）、可成长（品质递进）、可策略选择（6选1里程碑）

3.Skill与相近系统的边界区分
  ┌──────────┬──────────────┬──────────────┬──────────────┐
  │ 维度     │ Skill(技能)  │ 数据包       │ 书籍         │
  ├──────────┼──────────────┼──────────────┼──────────────┤
  │ 获取方式 │ 技能格/交流会 │ Boss战3选1   │ 书店格3选1   │
  │ 可管理性 │ 可装备/替换   │ 不可丢弃     │ 不可丢弃     │
  │ 槽位限制 │ 3个(可扩至4) │ 无上限(9个)  │ 无上限(36本) │
  │ 效果类型 │ 被动+主动    │ 仅被动       │ 仅被动       │
  │ 冷却机制 │ 主动型有冷却  │ 无冷却       │ 无冷却       │
  │ 可替换性 │ 可替换进仓库  │ 不可替换     │ 不可替换     │
  │ 设计定位 │ 策略选择型    │ 遗物收藏型   │ 知识积累型   │
  └──────────┴──────────────┴──────────────┴──────────────┘

二、Skill品质体系（统一规范）
========================================

1.五个品质等级
  - 普通(Common)：白色边框，小幅单一效果
  - 优秀(Uncommon)：绿色边框，中等效果
  - 稀有(Rare)：蓝色边框，较强效果+条件触发
  - 史诗(Epic)：紫色边框，强力效果+复杂机制
  - 传说(Legendary)：金色边框，极强效果+独特机制

2.品质与效果强度的统一规范（以"坚韧意志"系列为例）
  ┌──────────┬──────────────────────────────────────┐
  │ 品质     │ 效果                                 │
  ├──────────┼──────────────────────────────────────┤
  │ 普通     │ 坚韧意志：战斗开始时安全等级+1       │
  │ 优秀     │ 坚韧意志+：战斗开始时安全等级+2      │
  │ 稀有     │ 坚韧意志++：战斗开始时安全等级+3     │
  │ 史诗     │ 钢铁意志：战斗开始时安全等级+3，     │
  │          │ 且首次受到渗透等级降低时减半          │
  │ 传说     │ 不屈意志：战斗开始时安全等级+5，     │

  注意：不同品质的同类技能名称有递进标识（+、++）或全新名称，不可出现同名不同效果

三、Skill触发类型体系（统一规范，6种）
========================================

1.被动触发（Passive）
  - 常驻生效，无需手动操作
  - 触发时机：战斗开始时自动应用
  - 示例：坚韧意志（战斗开始时安全等级+1/+2/+3）
  - 视觉反馈：战斗开始时技能图标闪烁1次

2.回合开始触发（turn_start）
  - 每回合开始时自动触发
  - 触发时机：恢复阶段之后、摸牌阶段之前
  - 示例：再生能力（每回合安全等级+1）
  - 视觉反馈：回合开始时技能图标发光+效果数字弹出

3.出牌触发（card_play）
  - 打出卡牌时触发
  - 触发时机：行动阶段出牌后立即判定
  - 示例：连击精通（连续出同类卡牌第3张效果+50%）
  - 视觉反馈：出牌时技能图标连线到打出的卡牌

4.关卡失败触发（on_defeat）
  - 关卡/Boss挑战失败时触发
  - 触发时机：战斗失败结算时
  - 示例：不屈意志（关卡失败时技术值扣除量减少20%）
  - 视觉反馈：失败画面中技能图标发光+减免数字弹出

5.主动释放（active）
  - 需要手动触发，有冷却时间
  - 触发时机：行动阶段，消耗1点行动点
  - 示例：时间停滞（冻结敌人1回合，冷却5回合）
  - 视觉反馈：技能释放动画+敌人冻结特效
  - 冷却显示：技能图标上覆盖灰色遮罩+剩余冷却回合数

6.地图触发（map_trigger）——新增类型
  - 在爬塔地图层面触发，非战斗内触发
  - 触发时机：踩中格子/区域效果/骰子投掷等地图操作时
  - 示例：
    ① 战术撤退（主动，冷却3层）：跳过当前关卡格回到上一格，不触发关卡战斗
    ② 轻装上阵（被动）：骰子最低点数为2（投出1时视为2）
    ③ 区域适应（被动）：W区域效果对玩家无效
    ④ 机会直觉（被动）：机会格事件中可看到1个额外隐藏选项
  - 视觉反馈：地图操作时技能图标在屏幕右上角闪烁
  - 冷却规则：地图触发型主动技能的冷却以"层"为单位（每层可使用1次），而非"回合"

========================================
四、Skill管理规则（统一规范）
========================================

1.技能槽
  - 基础上限：3个
  - 扩展方式：史诗品质技能"无限潜能"可将上限提升至4个
  - 技能槽在界面右侧显示，3-4个圆形槽位

2.技能添加
  - 技能槽未满：新技能直接添加到空槽位
  - 技能槽已满：弹出替换界面，选择替换某个旧技能（旧技能进入仓库）或放弃新技能

3.技能仓库
  - 被替换的技能进入仓库
  - 仓库中的技能可随时与已装备技能互换（非战斗状态下）
  - 仓库容量无限制

4.技能冷却
  - 战斗内主动技能：冷却以"回合"为单位，每场战斗结束后重置
  - 地图层面主动技能：冷却以"层"为单位，进入新层时重置
  - 被动技能和触发型技能：无冷却概念

========================================
五、Skill获取途径（统一规范）
========================================

1.技能格（免费）：踩上去免费获得1个随机技能，品质受层级概率限制
2.交流会格（付费）：花费核心权限购买技能，品质比技能格略高（优秀起步，无普通品质）
3.技术值里程碑奖励选项②（免费）：获得1个技能，品质受层级概率限制
4.机会格稀有事件（低概率）：获得1个技能，品质随机

========================================
六、Skill效果范围（统一规范）
========================================

1.战斗层面（主要）：安全等级加成、判定修正、卡牌效果增强、回合效果等
2.地图层面（少数）：骰子修正、区域效果减免、格子交互增强等
3.跨层保持：所有技能效果在层级之间保持
