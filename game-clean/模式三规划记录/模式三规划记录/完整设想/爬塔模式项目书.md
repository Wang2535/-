## 一、项目概述

### 1.1 模式定位

爬塔模式是网络安全桌游的核心游戏模式之一，采用Roguelike塔防策略玩法。玩家从第1层出发，逐层挑战至第9层，每层包含多个关卡格、Boss格、机会格、书店格、技能格和交流会格。玩家通过投掷骰子在地图上移动，挑战关卡获取卡牌和资源，最终击败第9层Boss通关。

### 1.2 核心设计理念

- **成长感**: 技术值从50到810的巨大跨度，象征从网络安全小白到安全大师的成长历程
- **策略性**: 里程碑奖励自由选择、技能搭配、数据包协同效应
- **风险与收益**: 关卡失败扣除技术值，但不会立即游戏结束
- **探索性**: 地图翻转机制、隐藏路径、随机事件

### 1.3 游戏流程概览

```
开始游戏 → 第1层起点 → 投骰移动 → 触发格子效果 → 挑战关卡/Boss
     ↑                                                    ↓
     ←←←←←←←←←← 失败扣技术值 ←←←←←←←←←←←←←←←←←←←←←←←← 成功获奖励
                                                              ↓
                                              击败Boss → 数据包奖励 → 下一层
                                                              ↓
                                              第9层Boss → 通关
```

## 二、游戏模式概述

### 2.1 模式特点

| 特点 | 描述 |
|------|------|
| 单局时长 | 约45-90分钟 |
| 难度曲线 | 逐层递增，第9层最高 |
| 随机性 | 关卡抽取、事件触发、技能获取均有随机要素 |
| 策略深度 | 资源管理、技能搭配、路线选择 |
| 成长系统 | 技术值、卡牌、技能、数据包、书籍五维成长 |

### 2.2 胜利与失败条件

**胜利条件**: 击败第9层Boss

**失败条件**: 技术值归零（唯一失败条件）

**例外**: 拥有"免死机会"效果时，技术值归零会恢复至1点

每层地图包含以下格子类型：

| 格子类型 | 数量 | 功能描述 |
|----------|------|----------|

| 书店格 | 1个 | 书籍选择与阅读 |

#### 3.2.2 关卡格状态系统

关卡格有五种状态：

| 状态 | 视觉表现 | 说明 |
|------|----------|------|
| 未访问 | 暗色调，灰色半透明，带锁定图标 | 尚未踩中 |

| 已通关 | 亮色调，金色发光边框，对勾标记 | 战斗胜利 |
| 已失败 | 灰色底色+红色叉号标记 | 战斗失败，可重新挑战或绕过 |

#### 3.2.3 关卡格难度系统

| 难度星级 | 颜色 | 技术值奖励 | 稀有卡牌概率 |
|----------|------|------------|--------------|
| ★ | 绿色 | +3 | 20% |
| ★★ | 蓝色 | +5 | 20% |
| ★★★ | 黄色 | +9 | 20% |
| ★★★★ | 橙色 | +12 | 35%（精英） |
| ★★★★★ | 红色 | +15 | 35%（精英） |

**精英关卡格**: 难度★★★★及以上

- 失败惩罚：技术值扣除量×1.5
- 胜利奖励：技术值收益×2，核心资源收益×2

### 3.3 特殊区域系统

#### 3.3.1 区域效果类型

| 区域类型 | 效果 | 视觉表现 |
|----------|------|----------|
| W区域（虚弱区） | 下次投掷骰子点数-1（最低为1） | 淡红色半透明覆盖 |
| N区域（知识区） | 获得随机书籍×1，核心信息+2，核心算力+2，技术值+3 | 淡蓝色半透明覆盖 |
| I区域（反转区） | 整张地图倒置（起点变终点） | 淡紫色半透明覆盖 |
| P区域（跳过区） | 跳过下一回合 | 淡黄色半透明覆盖 |
| S区域（加速区） | 额外投掷一次骰子 | 淡绿色半透明覆盖 |
| D区域（危险区） | 随机损失资源 | 深红色半透明覆盖 |

#### 3.3.2 区域叠加规则

**优先级顺序**: I区域 > D区域 > P区域 > W区域 > S区域 > N区域

**触发顺序**: 先触发区域效果，再触发格子效果

**例外**: L4街区事件优先于区域效果触发

## 四、核心规则系统

### 4.1 骰子与移动系统

#### 4.1.1 骰子规则
- 每回合投掷一个六面骰子（1-6点）
- 根据点数沿路径前进对应步数
- 骰子点数可被效果修正（W区域-1，S区域额外投掷，技能"轻装上阵"最低为2）

#### 4.1.2 路径选择规则
- 分叉路口由玩家选择方向
- 步数用完停在格子上，触发格子效果
- 步数用完停在路径中间，停留于上一个经过的格子
- 每层地图保证强连通性

#### 4.1.3 移动动画
- 贝塞尔曲线插值，短距离300ms，长距离500ms
- 移动轨迹残留光痕
- 到达时有弹性回弹效果

### 4.2 关卡分配系统

#### 4.2.1 142关分类方案

| 层级 | 主题 | 关卡数量 |
|------|------|----------|
| 第1层 | 病毒与恶意软件 | 16关 |
| 第2层 | 网络攻击与防御 | 16关 |
| 第3层 | 数据安全与隐私 | 16关 |
| 第4层 | 社会工程学 | 16关 |
| 第5层 | 工控与物联网 | 16关 |
| 第6层 | 移动与终端安全 | 16关 |
| 第7层 | 云安全与虚拟化 | 16关 |
| 第8层 | AI与新兴技术 | 15关 |
| 第9层 | 安全管理与合规 | 15关 |

#### 4.2.2 每层关卡抽取规则
1. 从对应主题关卡池随机抽取9个作为关卡格内容储备
2. 剩余6-7个作为Boss候选池
3. 从Boss候选池选取属性最高的1个作为Boss原型
4. Boss原型经过强化改造：渗透等级提升速度×1.5~2.0、防御卡牌效果减半、技能数量+1~2个

### 4.3 地图翻转机制

#### 4.3.1 触发条件
到达终点（Boss格）时，本层已通关的关卡格不足9个

#### 4.3.2 翻转效果
- 起点与终点倒置
- 随机将2-5个非关卡格转换为关卡格
- 已访问格子状态保留

#### 4.3.3 翻转限制
- 最多触发3次
- 第3次翻转后强制解锁Boss格挑战权限
- Boss格和交流会格不可被转换

#### 4.3.4 瞬移能力
累计通关9个关卡格后解锁，可直接瞬移到Boss格

### 4.4 层级解锁条件

| 条件 | 说明 |
|------|------|
| 基础条件 | 本层累计通关9个关卡格 |
| 例外 | 地图翻转3次后强制解锁Boss格 |
| 瞬移 | 通关9个关卡格后可直接瞬移到Boss格 |

- **效果**: 受到渗透等级降低时先消耗护盾值

- **获取途径**: 里程碑奖励、数据包、技能效果

### 6.5 Boss战特殊机制

#### 6.5.1 Boss基础强化
- 多阶段渗透等级条（阈值25/50时转换阶段）
- 渗透等级提升速度×1.5~2.0
- 防御卡牌效果减半

#### 6.5.2 Boss机制动态生成

Boss的特殊机制不是固定按层级分配，而是根据Boss关卡原型的特性标签动态生成：

| 特性标签 | 生成机制 |
|----------|----------|
| 【召唤型】 | 每X回合召唤1个辅助单位（minion/分身/傀儡） |
| 【控制型】 | 每X回合禁用技能/锁定槽位/强制弃牌 |
| 【恢复型】 | 渗透等级被降低时，部分转化为提升 |
| 【干扰型】 | 干扰手牌顺序/判定结果/资源恢复 |
| 【进化型】 | 战斗越长属性越高 |
| 【时限型】 | 仅X回合内击败机会 |
| 【分身型】 | 拥有分身，攻击有概率无效 |
| 【心理型】 | 随机禁用技能或施加负面效果 |

#### 6.5.3 Boss机制生成示例

| Boss原型特性 | 生成机制 |
|--------------|----------|
| 【召唤型】【病毒主题】 | "病毒增殖"：每3回合召唤1个小病毒minion |
| 【恢复型】【加密主题】 | "加密锁链"：渗透等级被降低时50%转化为提升 |
| 【时限型】【终极挑战】 | "最终审判"：仅10回合内击败机会 |

#### 6.5.4 Boss机制强度调整

根据层级调整机制触发频率和效果强度：
- 第1层：召唤间隔4回合
- 第9层：召唤间隔2回合

| L1 | 葫芦形（上小下大） | ①关卡格密度从上到下递增（病毒扩散）；②W区域集中在大圆底部；③存在"回流路径"（病毒变异回溯） |
| L2 | 双环形（内外环） | ①外环路径长但难度低，内环短但难度高；②存在"跨环连接"需解锁；③"网络节点格"可开启/关闭连接 |
| L3 | 同心圆堡垒形 | ①必须按外→中→内顺序通过；②每个环有"安全门格"；③越内圈难度越大 |
| L4 | 网格街区形 | ①每个街区独立区域效果；②"主干道"双向、"小巷"单向；③"街区事件格"触发专属事件 |
| L5 | 流水线树形 | ①分支代表生产线，选择后需走完；②"阻塞格"暂停分支；③汇合处有"质检关卡格" |
| L6 | 六边形蜂窝形 | ①只能沿边移动；②"信号盲区格"随机方向；③格子周期性"激活/休眠" |
| L7 | 云朵不规则形 | ①非固定格30%概率偏移；②"云层格"可传送；③边界周期性"膨胀/收缩" |
| L8 | 量子概率云形 | ①连接有"概率强度"；②"观测格"固定连接状态；③隐藏路径通过"坍缩"解锁 |
| L9 | 王座殿堂对称形 | ①CORE区域需按顺序踩格；②"御道格"奖励高难度高；③两侧对称格效果相同 |

### 7.3 地图特殊机制设计原则

1. **可视化**: 观察地图结构即可理解特殊机制
2. **策略性**: 多种路径选择，需根据状态选择最优路线
3. **主题契合**: 地图结构与安全主题强关联
4. **难度递进**: 高层地图结构更复杂
4. **难度梯度**: 沿主路径方向难度递增
5. **视觉平衡**: 格子分布均衡

## 九、进度与存档系统

### 9.1 层级过渡流程

1. 击败Boss → 播放胜利动画
2. 弹出数据包选择界面 → 选择1个数据包
3. 播放层级过渡动画
4. 加载新层地图 → 玩家出现在新层起点格
5. 新层关卡内容重新随机抽取

### 9.2 存档规则

| 项目 | 规则 |
|------|------|
| 自动存档时机 | 每个层级过渡时 |
| 存档内容 | 层数、位置、技术值、金币、核心资源、卡池、技能、数据包、已阅读书籍、已通关关卡 |
| 层内存档 | 不自动存档，退出后从本层起点重新开始 |
| 存档槽位 | 仅1个，新存档覆盖旧存档 |

### 9.3 重试选项

| 选项 | 效果 |
|------|------|
| 重新挑战 | 技术值恢复到失败前的值，从该战斗重新开始 |
| 从本层起点重新开始 | 回到起点，本层内获取的资源重置，跨层资源保留 |
| 完全重新开始 | 从第1层重新开始，所有进度清零 |

### 10.3 设计原则总结

1. **技术值设计理念**: 50→810的巨大跨度象征从网络安全小白到安全大师的成长历程
2. **里程碑奖励设计**: 技术值越高奖励越多，但需要玩家根据局势自由选择
3. **失败不即死**: 关卡失败扣除技术值但不立即结束，给予翻盘机会
4. **策略深度**: 资源管理、技能搭配、路线选择、数据包协同效应
5. **随机性与策略性平衡**: 随机事件增加重玩价值，但策略选择决定成败
