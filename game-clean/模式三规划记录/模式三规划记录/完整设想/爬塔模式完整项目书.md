## 一、项目概述

### 1.1 设计理念

爬塔模式是网络安全桌游的核心游戏模式之一，采用Roguelike设计理念，玩家需要逐层挑战9个安全主题层，每层包含随机抽取的关卡、Boss和丰富的奖励系统。

**核心设计目标**：
- **单局完整性**：每局游戏独立，失败后重新开始
- **成长感**：技术值从50到810的巨大跨度，象征从小白到大师的成长
- **策略深度**：资源管理、技能搭配、路线选择多维策略
- **探索性**：地图翻转机制、隐藏路径、随机事件

### 1.2 游戏流程概览

```
开始游戏 → 第1层起点 → 投骰移动 → 触发格子效果 → 挑战关卡/Boss
     ↑                                                    ↓
     ←←←←←←←←←← 失败扣技术值 ←←←←←←←←←←←←←←←←←←←←←←←← 成功获奖励
                                                              ↓
                                              击败Boss → 数据包奖励 → 下一层
                                                              ↓
                                              第9层Boss → 通关
```

### 1.3 胜利与失败条件

| 条件类型 | 说明 |
|----------|------|
| **胜利条件** | 击败第9层Boss |
| **失败条件** | 技术值归零（唯一失败条件） |
| **例外** | 拥有"免死机会"效果时，技术值归零会恢复至1点 |

## 二、游戏模式概述

### 2.1 模式特点

| 特点 | 描述 |
|------|------|
| 单局时长 | 约45-90分钟 |
| 难度曲线 | 逐层递增，第9层最高 |
| 随机性 | 关卡抽取、事件触发、技能获取均有随机要素 |
| 策略深度 | 资源管理、技能搭配、路线选择 |
| 成长系统 | 技术值、卡牌、技能、数据包、书籍五维成长 |

### 2.2 与关卡模式的关系

爬塔模式与关卡模式共享以下系统：
- 7阶段回合战斗系统
- 防御值系统（安全等级/渗透等级）
- 卡牌系统（科技树、品质分类）
- 胜利条件判定

爬塔模式独有系统：
- 技术值生存系统
- 地图移动与格子交互
- 数据包/技能/书籍奖励
- 核心资源系统

每层地图包含以下格子类型：

| 格子类型 | 数量 | 功能描述 |
|----------|------|----------|

**格子总数**: 16-22格（基础配置16格，部分层扩展至18-22格）

#### 3.2.2 关卡格状态系统

关卡格有五种状态：

| 状态 | 视觉表现 | 说明 |
|------|----------|------|
| 未访问 | 暗色调，灰色半透明，带锁定图标 | 尚未踩中 |
| 待处理 | 闪烁橙色提示 | 踩中但未选择进入，不可绕过 |

| 已通关 | 亮色调，金色发光边框，对勾标记 | 战斗胜利 |
| 已失败 | 灰色底色+红色叉号标记 | 战斗失败，可重新挑战或绕过 |

#### 3.2.3 关卡格难度系统

| 难度星级 | 颜色 | 技术值奖励 | 稀有卡牌概率 |
|----------|------|------------|--------------|
| ★ | 绿色 | +3 | 20% |
| ★★ | 蓝色 | +5 | 20% |
| ★★★ | 黄色 | +9 | 20% |
| ★★★★ | 橙色 | +12 | 35%（精英） |
| ★★★★★ | 红色 | +15 | 35%（精英） |

**精英关卡格**: 难度★★★★及以上
- 特殊视觉标识：红色锯齿边框+骷髅图标叠加
- 失败惩罚：技术值扣除量×1.5
- 胜利奖励：技术值收益×2，核心资源收益×2

#### 3.2.4 关卡格动态翻转机制

**触发条件**: 到达终点（Boss格）时，本层已通关的关卡格不足9个

**翻转效果**:
1. 起点与终点倒置
2. 随机将2-5个非关卡格转换为关卡格
3. 已访问格子状态保留

**翻转限制**: 最多触发3次，第3次后强制解锁Boss格挑战权限

**瞬移能力**: 累计通关9个关卡格后解锁，可直接瞬移到Boss格

### 3.3 特殊区域系统

#### 3.3.1 区域效果类型

| 区域类型 | 效果 | 视觉表现 |
|----------|------|----------|
| W区域（虚弱区） | 下次投掷骰子点数-1（最低为1） | 淡红色半透明覆盖 |
| N区域（知识区） | 获得随机书籍×1，核心信息+2，核心算力+2，技术值+3 | 淡蓝色半透明覆盖 |
| I区域（反转区） | 整张地图倒置（起点变终点） | 淡紫色半透明覆盖 |
| P区域（跳过区） | 跳过下一回合 | 淡黄色半透明覆盖 |
| S区域（加速区） | 额外投掷一次骰子 | 淡绿色半透明覆盖 |
| D区域（危险区） | 随机损失资源 | 深红色半透明覆盖 |

#### 3.3.2 区域叠加规则

**优先级顺序**: I区域 > D区域 > P区域 > W区域 > S区域 > N区域

**触发顺序**: 先触发区域效果，再触发格子效果

**例外**: L4街区事件优先于区域效果触发

## 四、核心规则系统

### 4.1 骰子与移动系统

#### 4.1.1 骰子规则
- 每回合投掷一个六面骰子（1-6点）
- 根据点数沿路径前进对应步数
- 骰子点数可被效果修正（W区域-1，S区域额外投掷，技能"轻装上阵"最低点数为2）

#### 4.1.2 路径选择规则
- 分叉路口由玩家选择方向
- 步数用完停在格子上触发效果
- 步数用完停在路径中间则停留在上一个经过的格子
- 每层地图保证强连通性

#### 4.1.3 移动动画
- 贝塞尔曲线插值平滑移动
- 短距离300ms，长距离500ms
- 移动轨迹残留淡淡光痕

### 4.2 关卡分配系统

#### 4.2.1 142关分类方案

| 层级 | 主题 | 关卡数 |
|------|------|--------|
| L1 | 病毒与恶意软件 | 16关 |
| L2 | 网络攻击与防御 | 16关 |
| L3 | 数据安全与隐私 | 16关 |
| L4 | 社会工程学 | 16关 |
| L5 | 工控与物联网 | 16关 |
| L6 | 移动与终端安全 | 16关 |
| L7 | 云安全与虚拟化 | 16关 |
| L8 | AI与新兴技术 | 15关 |
| L9 | 安全管理与合规 | 15关 |

#### 4.2.2 Boss生成规则
1. 从剩余关卡中选取属性最高的1个作为Boss原型
2. 选取标准：综合战力评分最高 > 难度星级最高 > 主题代表性最强
3. Boss强化：渗透等级提升速度×1.5~2.0、防御卡牌效果减半、技能数量+1~2个

### 4.3 关卡挑战规则

#### 4.3.1 战斗胜利奖励

#### 4.3.2 战斗失败惩罚

| L6 | 210 | 350 |

### 7.3 路径规划原则

1. **强连通性**: 从任意格子可达其他所有格子
2. **环路保证**: 至少1个≥4格的闭环路径
3. **功能格可达性**: 机会格不在必经点上，书店格位于中等深度
4. **难度梯度**: 沿主路径方向难度递增
5. **视觉平衡**: 格子分布均衡，功能格分散布置

## 九、进度与存档系统

### 9.1 层级过渡流程

1. 击败Boss → 播放胜利动画
2. 弹出数据包选择界面 → 选择1个数据包
3. 播放层级过渡动画
4. 加载新层地图 → 玩家出现在新层起点格
5. 新层关卡内容重新随机抽取

### 9.2 存档规则

| 项目 | 规则 |
|------|------|
| 自动存档时机 | 每个层级过渡时 |
| 存档内容 | 层数、位置、技术值、金币、核心资源、卡池、技能、数据包、已阅读书籍、已通关关卡 |
| 层内存档 | 不自动存档，退出后从本层起点重新开始 |
| 存档槽位 | 仅1个，新存档覆盖旧存档 |

### 9.3 重试选项

| 选项 | 效果 |
|------|------|
| 重新挑战 | 技术值恢复到失败前的值，从该战斗重新开始 |
| 从本层起点重新开始 | 回到起点，本层内获取的资源重置，跨层资源保留 |
| 完全重新开始 | 从第1层重新开始，所有进度清零 |
