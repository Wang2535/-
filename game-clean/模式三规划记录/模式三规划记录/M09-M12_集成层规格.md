## M09: 功能格执行引擎 (CellActionExecutor)

### 9.1 模块定位与职责

| 属性 | 说明 |
|------|------|
| **职责范围** | 执行玩家到达各功能格后的具体逻辑（机会事件/书店选书/Skill获取/BOSS战/层间过渡） |
| **输入** | 格子类型+数据(M04/M06)、执行上下文、玩家当前状态(M11) |
| **输出** | 各类 `CellActionResult`、奖励发放请求、状态变更通知 |
| **依赖** | M01(types), M02(constants), M03(utils), M06(cell state), M10(rewards), M11(progress) |
| **被依赖** | M08(movement - 调用执行), M12(integrator - 协调) |
| **技术栈** | TypeScript + React (含弹窗UI协调) |

### 9.4 各格子类型执行流程详解

#### 9.4.1 战斗格 (BattleCell)

```
┌─────────────────────────────────────────────┐
│         executeBattle(cell, context)         │
└──────────────────┬──────────────────────────┘
                   │
                   ▼
┌─────────────────────────────────────────────┐
│ 1. 前置检查                                  │
│    - 是否已 completed？→ 跳过（已打过）        │
│    - 玩家HP是否足够进入？                     │
└──────────────────┬──────────────────────────┘
                   │
                   ▼
┌─────────────────────────────────────────────┐
│ 2. 准备战斗入口UI                            │
│    构造 battleEntrance 合约数据               │
│    通过 UIBridge 显示战斗入口弹窗             │
│    等待玩家选择：确认进入 / 撤退             │
└──────────────────┬──────────────────────────┘
                   │ 确认进入
                   ▼
┌─────────────────────────────────────────────┐
│ 3. 发出 BATTLE_START 事件                    │
│    → 外部战斗系统接管                        │
│    → 等待 BATTLE_END 事件                    │
└──────────────────┬──────────────────────────┘
                   │
                   ▼
┌─────────────────────────────────────────────┐
│ 4. 处理战斗结果                              │
│    if victory:                               │
│      a. M10 发放战斗奖励                     │
│      b. 更新 cell.state → completed          │
│      c. 解锁邻居格子                         │
│      d. 返回 BattleActionResult(victory)     │
│    else:                                     │
│      a. cell.state → unlocked (可重试)       │
│      b. 返回 BattleActionResult(defeat)      │
└─────────────────────────────────────────────┘
```

#### 9.4.2 机会格 (ChanceCell)

```
executeChance(cell, context):
  1. 从 cell.eventPoolIds 中选取事件池
  2. 加权随机抽取1个 ChanceEvent
  3. 如果有选项 → 显示 chanceEvent UI，等待选择
  4. 如果无选项（即时效果）→ 直接结算
  5. 应用结果：
     - 正面效果 → M10 发放奖励
     - 负面效果 → 扣除资源
     - 选择型 → 根据选择结算
  6. 更新 visitCount
  7. 返回 ChanceActionResult
```

#### 9.4.3 书店格 (BookstoreCell)

```
executeBookstore(cell, context):
  1. 从 cell.bookPoolTheme 对应的主题书籍池中
     随机抽取 bookCountPerVisit(默认3) 本书
  2. 构造 bookstoreDisplay 合约数据
  3. 显示书店UI弹窗
  4. 等待玩家选择一本书 或 离开
  5. 选择后:
     a. M10 处理书籍获取（标记已读）
     b. 应用书籍效果
     c. 记录到 readBooks
  6. 返回 BookstoreActionResult
```

#### 9.4.4 Skill格 (SkillCell)

```
executeSkill(cell, context):
  1. 根据 cell.tierProbabilityTable 抽取品质
  2. 从该品质池中随机抽取1个 Skill
  3. 构造 skillOffer 合约数据
  4. 显示Skill获取UI
  5. 玩家选择:
     a. 直接装备（如果槽位有空）
     b. 替换已有技能（选择替换哪个槽位）
     c. 放弃获取
  6. 确认后:
     a. M10 处理Skill获取
     b. 更新 activeSkillIds / ownedSkills
  7. 返回 SkillActionResult
```

#### 9.4.5 Boss格 (BossCell)

```
executeBoss(cell, context):
  1. 前置检查: BOSS是否已击败？
  2. 类似战斗格流程，但敌人更强（enhancementLevel）
  3. 战斗胜利后:
     a. 触发 BOSS_DEFEATED 事件
     b. 从 cell.dataPacketPoolIds 中随机取3个
     c. 构造 bossReward 合约（三选一数据包）
     d. 等待玩家选择
     e. M10 发放选中的数据包
     f. 标记 bossDefeated = true
     g. 如果不是第9层 → 在boss位置生成End格
  4. 返回 BossActionResult
```

#### 9.4.6 End格 (EndCell)

```
executeEnd(cell, context):
  1. 构造 layerTransition 合约数据
  2. 显示层间过渡动画/UI
  3. 玩家确认后:
     a. 触发 LAYER_COMPLETE 事件
     b. M11 记录本层完成快照
     c. 如果 destinationLayer > 0:
        - M12 加载下一层数据
        - 重置位置到下一层起点
     d. 如果 destinationLayer === 0:
        - 触发 GAME_COMPLETE 事件
        - 显示最终结算画面
  4. 返回 ActionResultBase
```

## M10: 奖励系统集成 (RewardSystem)

### 10.1 模块定位与职责

| 属性 | 说明 |
|------|------|
| **职责范围** | 统一管理所有奖励的发放、收集、冲突检测与存档同步（数据包/书籍/Skill/战斗奖励） |
| **输入** | 奖励请求来源(M09)、玩家当前持有物(M11)、配置常量(M02) |
| **输出** | 奖励发放结果、库存变更、冲突解决建议 |
| **依赖** | M01(types), M02(constants), M03(utils) |
| **被依赖** | M09(execution), M07(zone - N区赠书), M11(progress - 存档读取) |
| **技术栈** | TypeScript (纯逻辑) |

### 10.2 核心数据结构

```typescript
// ====== 奖励请求 ======
interface RewardRequest {
  source: RewardSource;
  rewardType: 'data_packet' | 'book' | 'skill' | 'card' | 'gold' | 'heal';
  items: RewardItem[];
  context: RewardContext;
}

type RewardSource =
  | 'battle_victory'       // 战斗胜利
  | 'boss_defeat'          // BOSS战胜利
  | 'chance_event'         // 机会事件
  | 'zone_effect'          // 区域效果(N区)
  | 'bookstore_purchase'   // 书店购买
  | 'skill_grant'          // Skill格获取
  | 'special';             // 特殊来源

interface RewardItem {
  id: string;                    // 物品ID
  quantity: number;              // 数量
  metadata?: Record<string, unknown>;
}

interface RewardContext {
  playerId: string;
  layerNumber: number;
  turnNumber: number;
  triggerCellId?: string;
}

// ====== 奖励发放结果 ======
interface RewardResult {
  success: boolean;
  grantedItems: GrantedItem[];
  rejectedItems: RejectedItem[];
  conflictsResolved: ConflictResolution[];
  inventorySnapshot: InventorySnapshot;
}

interface GrantedItem {
  id: string;
  type: string;
  name: string;
  grantedAt: number;
  source: RewardSource;
}

interface RejectedItem {
  id: string;
  reason: RejectReason;
  suggestion?: string;
}

type RejectReason =
  | 'inventory_full'            // 背包已满
  | 'conflict_exclusive'        // 互斥冲突
  | 'already_owned'             // 已拥有
  | 'max_limit_reached'         // 达到上限
  | 'layer_restriction'         // 层级限制
  | 'condition_unmet';          // 条件不满足

interface ConflictResolution {
  type: 'replace' | 'discard' | 'merge';
  itemId: string;
  conflictingWith: string;
  resolvedBy: 'auto' | 'player_choice';
}

// ====== 库存快照 ======
interface InventorySnapshot {
  dataPackets: DataPacket[];           // 当前拥有的数据包
  ownedSkills: Skill[];                // 仓库中的技能
  activeSkillIds: string[];            // 激活的技能ID
  readBooks: Book[];                   // 已读书籍
  gold: number;
  cards: string[];                     // 卡牌ID列表
  hp: number;
  maxHp: number;
  timestamp: number;
}
```

### 10.4 冲突检测与解决规则

```typescript
/**
 * 数据包冲突规则
 * 1. 互斥组：某些数据包不能同时拥有（如两个直接冲突的效果）
 * 2. 上限检查：每种类型最多拥有N个
 * 3. 唯一性：同一数据包不能重复获得
 */
const DATA_PACKET_CONFLICT_RULES: ConflictRule[] = [
  {
    type: 'exclusive_group',
    groups: [
      ['DP_T1_01', 'DP_T1_02'],  // 示例互斥组
      // ... 更多互斥关系
    ],
    resolution: 'player_choice',  // 让玩家选择保留哪个
  },
  {
    type: 'unique',
    check: (itemId, inventory) => inventory.dataPackets.some(p => p.id === itemId),
    resolution: 'reject',          // 重复则拒绝
  },
  {
    type: 'max_count',
    maxCount: REWARD_CONFIG.DATA_PACKET_MAX_OWNED,
    resolution: 'player_choice',    // 超出时让玩家选择丢弃
  },
];

/**
 * 技能冲突规则
 * 1. 槽位限制：激活槽位最多3个
 * 2. 仓库无限制（但需要管理）
 * 3. 替换流程：选择要替换的已有技能
 */
const SKILL_CONFLICT_RULES: ConflictRule[] = [
  {
    type: 'slot_limit',
    maxSlots: REWARD_CONFIG.SKILL_MAX_ACTIVE_SLOTS,
    resolution: 'replace_or_warehouse',
  },
  {
    type: 'unique_active',
    check: (skillId, inventory) => inventory.activeSkillIds.includes(skillId),
    resolution: 'warehouse',       // 已激活则放入仓库
  },
];

/**
 * 书籍冲突规则
 * 1. 同一本书只能读一次（标记isRead）
 * 2. 无数量上限
 */
const BOOK_CONFLICT_RULES: ConflictRule[] = [
  {
    type: 'unique_read',
    check: (bookId, inventory) => inventory.readBooks.some(b => b.id === bookId),
    resolution: 'skip',            // 已读过则跳过（不重复给效果）
  },
];
```

### 10.5 奖励处理流程

```
┌──────────────────────────────────────────────┐
│           processReward(request)              │
└──────────────────┬───────────────────────────┘
                   │
                   ▼
┌──────────────────────────────────────────────┐
│ 1. 解析请求                                   │
│    根据 rewardType 分发到对应的处理器          │
└──────────────────┬───────────────────────────┘
                   │
                   ▼
┌──────────────────────────────────────────────┐
│ 2. 冲突预检                                   │
│    for each item in request.items:            │
│      conflicts = checkConflicts(item.id)      │
│      if has conflict:                         │
│        → 加入待解决队列                       │
│      else:                                    │
│        → 直接通过                             │
└──────────────────┬───────────────────────────┘
                   │
                   ▼
┌──────────────────────────────────────────────┐
│ 3. 解决冲突                                   │
│    自动解决的 → 直接处理                      │
│    需要玩家选择的 → 暂停，等待UI回调           │
│    （通过 Promise / Event 解决异步等待）       │
└──────────────────┬───────────────────────────┘
                   │
                   ▼
┌──────────────────────────────────────────────┐
│ 4. 执行发放                                   │
│    data_packet → inventory.dataPackets.push() │
│    book → mark as read + apply effect         │
│    skill → add to active or warehouse         │
│    card/gold/hp → direct modify               │
└──────────────────┬───────────────────────────┘
                   │
                   ▼
┌──────────────────────────────────────────────┐
│ 5. 快照 & 回调                                 │
│    更新 inventorySnapshot                     │
│    通知 M11 进度更新                           │
│    返回 RewardResult                          │
└──────────────────────────────────────────────┘
```

```typescript
/**
 * 存档存储策略
 * 使用 localStorage 作为主要存储（快速访问）
 * 可选 IndexedDB 作为大数据量备用
 */
class SaveStorage {
  private readonly STORAGE_PREFIX = 'tower_mode_save_';
  private readonly MAX_SAVES = 10;
  private readonly AUTO_SAVE_KEY = 'autosave';

  /** 保存到指定槽位 */
  async save(slotId: string, data: TowerSaveData): Promise<void> {
    const serialized = JSON.stringify(data);
    
    // localStorage 存储（大小限制 ~5MB）
    localStorage.setItem(
      this.STORAGE_PREFIX + slotId,
      serialized
    );

    // 同时写入 IndexedDB（作为备份）
    await this.writeToIndexedDB(slotId, data);
  }

  /** 从指定槽位加载 */
  async load(slotId: string): Promise<TowerSaveData | null> {
    // 优先从 localStorage 读取
    const localData = localStorage.getItem(this.STORAGE_PREFIX + slotId);
    if (localData) {
      return JSON.parse(localData) as TowerSaveData;
    }

    // fallback 到 IndexedDB
    return this.readFromIndexedDB(slotId);
  }

  /** 自动保存（覆盖式） */
  async autoSave(data: TowerSaveData): Promise<void> {
    await this.save(this.AUTO_SAVE_KEY, data);
  }

  /** 列出所有存档 */
  listSlots(): SaveMeta[] {
    const slots: SaveMeta[] = [];
    for (let i = 0; i < localStorage.length; i++) {
      const key = localStorage.key(i);
      if (key?.startsWith(this.STORAGE_PREFIX) && key !== this.STORAGE_PREFIX + this.AUTO_SAVE_KEY) {

        if (raw) {
          const data = JSON.parse(raw) as TowerSaveData;
          slots.push(data.saveMeta);
```

### 12.6 主组件结构 (TowerModeApp.tsx)

```tsx
// 文件位置: tower-mode/TowerModeApp.tsx

function TowerModeApp({ onSaveExit }: Props) {
  const controller = useRef<TowerModeController | null>(null);
  const [renderState, setRenderState] = useState<TowerRenderState | null>(null);
  const [phase, setPhase] = useState<GamePhase>('idle');

  useEffect(() => {
    controller.current = new TowerModeController();
    controller.current.initialize().then(() => {
      controller.current!.onStateChange(setRenderState);
      controller.current!.onPhaseChange(setPhase);
    });
    return () => controller.current?.dispose();
  }, []);

  if (!renderState || phase === 'idle') {
    return <TowerStartScreen onStart={handleStart} onLoad={handleLoad} />;
  }

  return (
    <div className="tower-mode-container">
      {/* 顶部信息栏 */}
      <TowerHUD stats={renderState.playerStats} phase={phase} />

      {/* 地图视图 */}
      <TowerMapView
        layerData={renderState.layerData!}
        cells={renderState.cells}
        currentPosition={renderState.currentPosition}
        onCellClick={handleCellClick}
      />

      {/* 移动控制区 */}
      <MovementControl
        diceResult={renderState.diceResult}
        moveOptions={renderState.moveOptions}
        onRollDice={handleRollDice}
        onMove={handleMoveTo}
        disabled={!canAct()}
      />

      {/* 弹窗层（条件渲染） */}
      {renderState.uiState.activeModal === 'battle_entrance' && (
        <BattleEntranceModal
          data={renderState.uiState.modalData as ExecutionUIContract['battleEntrance']}
          onConfirm={() => interactWithCurrentCell('confirm')}
          onRetreat={() => interactWithCurrentCell('retreat')}
        />
      )}
      {renderState.uiState.activeModal === 'chance_event' && (
        <ChanceEventModal ... />
      )}
      {renderState.uiState.activeModal === 'bookstore' && (
        <BookstoreModal ... />
      )}
      {renderState.uiState.activeModal === 'skill_offer' && (
        <SkillPanel ... />
      )}
      {renderState.uiState.activeModal === 'boss_reward' && (
        <DataPacketSelector ... />
      )}
      {renderState.uiState.activeModal === 'layer_transition' && (
        <LayerTransition ... />
      )}
      {renderState.uiState.activeModal === 'game_complete' && (
        <GameCompleteScreen stats={...} />
      )}

      {/* 通知系统 */}
      <NotificationContainer
        notifications={renderState.uiState.notifications}
      />
    </div>
  );
}
```
