## 一、海幸地图分析

### 1.1 参考图核心特征

基于海幸参考图（SRayLand），提取以下核心结构特征：

```
┌─────────────────────────────────────────┐
│                  顶部                    │
│            （葫芦嘴/入口）               │
│                 ╱ ╲                     │
│                ╱   ╲                    │
│         ┌─────┼─────┐                  │
│         │  上环（小圆） │              │
│         │  ┌──┴──┐    │               │
│         │  │ 内部 │    │               │
│         │  │十字  │    │               │
│         │  └──┬──┘    │               │
│         └─────┼─────┘                  │
│               │                        │
│     ┌──────────┴──────────┐           │
│     │                     │           │
│     │   下环（大圆/主体）  │           │
│     │  ┌──────┬──────┐   │           │
│     │  │  W   │  N   │   │ ← 四象限  │
│     │  ├──────┼──────┤   │   区域    │
│     │  │  I   │  P   │   │   标记    │
│     │  └──────┴──────┘   │           │
│     │          end →      │           │
│     └─────────────────────┘           │
│            SRayLand                   │
└─────────────────────────────────────────┘
```

### 1.2 结构要素拆解

| 要素 | 描述 | 设计借鉴点 |
|------|------|-----------|
| **葫芦形主体** | 上小下大的双圆叠加形态 | 象征"积累-成长"的递进感 |
| **外环路径** | 沿轮廓边缘的环形行进路线 | 确保玩家可遍历所有区域 |
| **内环十字交叉** | 中心区域的十字形通道 | 提供捷径与战略选择 |
| **W/N/I/P四象限** | 底部大圆划分为4个功能区域 | 功能分区明确 |
| **end标记** | 终点位置标识 | 明确目标方向 |
| **彩色格子** | 橙黄白相间的路径节点 | 视觉节奏与引导 |

### 1.3 设计转化原则

将海幸地图特征转化为9层塔每层的独立造型时，遵循：

1. **保留环形骨架**：每层至少包含一条主环路
2. **变异主体形状**：根据主题调整主体轮廓（非全部葫芦形）
3. **维持十字内核**：中心区域保留交叉连接能力
4. **功能分区继承**：W/N/I/P/S五区概念在各层以不同方式体现
5. **视觉差异化**：每层通过形状+颜色+纹理实现独特识别度

## 二、统一坐标系定义

### 2.1 坐标系规范

```
┌────────────────────────────────────┐
│                                    │
│        Y轴（正方向向上）            │
│            ↑                       │
│            │                       │
│            │                       │
│   ←───────┼───────→ X轴           │
│     (负)  │    (正)               │
│            │                       │
│     原点(0,0) 位于地图几何中心     │
│                                    │
└────────────────────────────────────┘
```

### 2.2 坐标约定

| 参数 | 定义 | 说明 |
|------|------|------|
| **坐标表示** | `grid[x][y]` | x为水平索引，y为垂直索引 |
| **原点位置** | `(0, 0)` | 地图几何中心 |
| **X范围** | `-8 ~ +8` | 共17列 |
| **Y范围** | `-6 ~ +6` | 共13行 |
| **有效格子** | 非null值的位置 | null表示空白/不可通行 |
| **方向枚举** | N/E/S/W/NE/NW/SE/SW | 8方位 |

### 2.3 方向常量定义

```typescript
// 方向向量（用于路径计算）
export const DIRECTION_VECTORS = {
  N:  { dx:  0, dy: +1 },   // 北：向上
  NE: { dx: +1, dy: +1 },   // 东北
  E:  { dx: +1, dy:  0 },   // 东：向右
  SE: { dx: +1, dy: -1 },   // 东南
  S:  { dx:  0, dy: -1 },   // 南：向下
  SW: { dx: -1, dy: -1 },   // 西南
  W:  { dx: -1, dy:  0 },   // 西：向左
  NW: { dx: -1, dy: +1 },   // 西北
} as const;

export type Direction = keyof typeof DIRECTION_VECTORS;
```

### 2.4 格子数据结构

```typescript
interface GridCell {
  /** 格子坐标 */
  position: { x: number; y: number };
  /** 格子类型 */
  type: 'combat' | 'elite' | 'boss' | 'chance' | 'bookshop' | 'skill' | 'end' | 'start' | 'normal';
  /** 格子ID（全局唯一） */
  id: string;
  /** 所属区域标识 */
  region: 'W' | 'N' | 'I' | 'P' | 'S' | 'CORE';
  /** 连接的邻居格子ID列表 */
  connections: string[];
  /** 是否为路径必经点 */
  isPathNode: boolean;
}
```

### 2.5 区域划分约定

| 区域代号 | 全称 | 含义 | 典型内容 |
|---------|------|------|---------|
| **W** | West | 西侧区域 | 战斗/挑战类关卡格 |
| **N** | North | 北侧区域 | 精英/高难类关卡格 |
| **I** | Inner | 内侧区域 | 事件/机会类功能格 |
| **P** | Path / East | 路径/东侧区域 | 过渡/普通类关卡格 |
| **S** | South | 南侧区域 | 休息/恢复类功能格 |
| **CORE** | Core | 中心区域 | Boss/终点格 |

## 三、9层独立造型方案

> 每层总格子数控制在 **15~20格**（含功能格），其中：
> - 关卡格（combat）：9个
> - 机会格（chance）：2个
> - 书店格（bookshop）：1个
> - 技能格（skill）：1个
> - 终点/Boss格（end/boss）：1个
> - 起点格（start）：1个
> - **合计：15格基础配置**（部分层可扩展至17-20格增加过渡格）

## 四、格子容量与路径规划原则

### 4.1 格子容量标准

| 层数指标 | 标准值 | 允许范围 | 说明 |
|---------|--------|---------|------|
| 总格子数 | 16 | 15 ~ 20 | 含所有类型格 |
| 关卡格(combat) | 9 | 8 ~ 10 | 对应每层9关 |
| 精英格(elite) | 1 | 1 ~ 2 | 高难度挑战 |
| Boss格(boss/end) | 1 | 固定1 | 每层唯一 |
| 机会格(chance) | 2 | 1 ~ 3 | 随机事件 |
| 书店格(bookshop) | 1 | 固定1 | 卡牌获取 |
| 技能格(skill) | 1 | 固定1 | 技能学习 |
| 起点格(start) | 1 | 固定1 | 层入口 |

### 4.2 路径规划五大原则

#### 原则一：强连通性

```
✅ 要求：从任意格子出发，存在路径到达其他所有格子
✅ 要求：不存在"孤岛"格子（仅自身或无法到达其他格）
✅ 要求：不存在"死胡同"（除Boss格外，所有格至少2条出路）

反例（禁止）:
  A → B → C → D(Boss)
      ↑
      E        ← E只能到B，形成不良体验
```

#### 原则二：环路保证

```
✅ 要求：每层必须包含至少一个环路（闭环路径）
✅ 要求：环路长度 ≥ 4格（避免过短环路失去策略意义）
✅ 建议：环路数量 1 ~ 3 个

示例:
  A → B → C → D → A   (4格最小环路 ✓)
  A → B → C → D → E → F → A   (6格推荐环路 ✓)
```

#### 原则三：功能格可达性

```
✅ 要求：机会格(chance)不在主路径必经点上
       （允许绕过，保持随机性）
✅ 要求：书店格(bookshop)位于中等深度位置
       （既不太早获得也不太晚无法使用）
✅ 要求：技能格(skill)相对居中或略偏后
       （需要一定探索后解锁）
✅ 要求：起点(start)和终点(end)位置明确
       （起点易找，终点有仪式感）
```

#### 原则四：难度梯度

```
✅ 要求：沿主路径方向，难度逐渐递增
✅ 要求：精英格位于路径中后段（40%~70%深度）
✅ 要求：Boss格位于最深/最难到达位置
✅ 要求：捷径通常伴随更高风险（如经过精英格）

距离定义:
  depth = (从起点到该格的最短路径长度) / (总路径最大长度)

难度分配参考:
  depth 0%~20%:   普通关卡（热身）
  depth 20%~50%:  普通关卡 + 1个机会格
  depth 50%~70%:  精英关卡 + 功能格集中区
  depth 70%~100%: 高难关卡 + Boss
```

#### 原则五：视觉平衡

```
✅ 要求：格子分布在X/Y方向上尽量均衡
✅ 要求：避免某一区域过度密集（>5格聚集）
✅ 要求：空旷区域（无格子）不宜过大（连续空位≤3）
✅ 要求：功能格分散布置（不集中在同一象限）

密度检查公式:
  density = (区域内格子数) / (区域面积)
  推荐: 0.3 ≤ density ≤ 0.7
```
