# 第九轮 vs 设想差距分析报告 — 聚焦分地图差异化

## 核心结论

**第九轮在游戏引擎和组件层面取得了决定性突破，但"分地图差异化"这一用户最关心的领域，目前仅完成了约55%——主要停留在"换色"层面，缺乏形状、拓扑、机制视觉化的深度差异。**

---

## 一、差距总览（按严重度排序）

### P0 — 阻塞性差距（必须第十轮解决）

| ID | 差距描述 | 当前状态 | 设想要求 | 影响 |
|----|---------|---------|---------|------|
| **Gap-P0-1** | **所有9层使用完全相同的葫芦形比例** | 上圆radius=18/下圆radius=35/连接width=8，所有层一致 | 每层应有独特造型(如L6六角迷宫/L8坍缩变形) | 玩家切换层时感觉"只是换了个颜色"，缺乏新鲜感 |
| **Gap-P0-2** | **所有9层格子数量和分布相同** | U0-U5(6个上圆)+C0-C1(2个连接)+L0-L11(12个下圆)=20格，每层一样 | L2应更密集(网络节点)/L4应分散(街区)/L6应不规则(迷路) | 机制无法通过地图结构体现 |
| **Gap-P0-3** | **层级特殊机制仅存在于数据层面，视觉未体现** | layerMechanic.type='teleport'等存在但渲染器不读取 | L6迷路应有六角网格可视化/L8坍缩应有路径消失动画 | "有机制无感知"，玩家不知道当前层的特殊性 |

## 二、分地图差异化深度诊断

### 2.1 当前各层实际差异清单

对9层visualData进行逐字段对比后，实际存在的差异:

| 差异维度 | 是否有差异 | 差异程度 | 评价 |
|----------|-----------|---------|------|
| background.primary/secondary | ✅ 有 | ⭐⭐⭐ | 每层不同，营造基础氛围差异 |
| border.colors (边框配色) | ✅ 有 | ⭐⭐⭐ | 9种不同配色方案 |
| zoneBackgrounds.fillColor | ✅ 有 | ⭐⭐ | opacity微调但色调相同(W红/N青...) |
| decorations (装饰物) | ✅ 有 | ⭐⭐ | 类型/数量/位置不同 |
| layerMechanic.type | ✅ 有 | ⭐⭐⭐ | 9种不同机制类型(数据层面) |
| **gourdCoordinates (葫芦形状)** | ❌ 无 | ☆ | **全部相同** |
| **cells (格子布局)** | ❌ 无 | ☆ | **全部20格相同位置** |
| **connections (连接关系)** | ❌ 无 | ☆ | **全部相同路径** |
| **quadrantLabels 区域划分** | ❌ 基本无 | ⭐ | L5用了S/D替代I/P，其余相同 |
| **cellVisualStyles (格子样式)** | ❌ 基本无 | ⭐ | 仅border颜色随层变化 |
| **pathVisualStyles (路径样式)** | ❌ 无 | ☆ | **全部相同** |

**结论**: 11个差异化维度中，仅有5个有实质性差异(45%)，**最关键的形状/拓扑/连接/路径4个维度完全无差异(0%)**。

## 三、第十轮优先级建议

### 必做（P0 × 3）

1. **GourdShapeFactory — 葫芦形变体生成器**
   - 输入: layerNumber + mechanicType
   - 输出: 该层专属的 upperCircle/lowerCircle/connector 几何参数
   - 实现: L6→扁平六角 / L8→不对称坍缩 / L9→扩展宫殿 / L3→三环嵌套

2. **PerLayerTopologyGenerator — 分层拓扑生成器**
   - 为每层生成不同的 cells 分布和 connections 连接方式
   - L2: 密集节点簇(30+小格)
   - L4: 分散街区块(多个独立区域)
   - L6: 六角网格(蜂窝状)
   - L8: 动态路径(部分路径会消失)

3. **MechanicVisualizer — 机制可视化器**
   - 读取当前层 layerMechanic.type
   - 在地图上渲染对应的视觉效果:
     - acceleration: W区连击进度条
     - jump: 可跳跃目标高亮圈
     - sequence: 三环访问顺序指示
     - blockade: 被阻塞路径红色X标记
     - teleport: 迷路雾效+随机传送门
     - drift: 方向偏移箭头场
     - collapse: 坍缩裂纹动画
     - protocol: 正确踩格顺序指引线

### 强烈建议（P1 × 5）

4. **LayerTransitionFX — 层级专属转场特效**
5. **PerLayerPathStyle — 分层路径渲染**
6. **ZoneShapeVariants — 区域形状变体**
7. **L9 Ultimate Boss Enhancement — 终极Boss视觉升级**
8. **Engine-UI Wiring — 引擎与UI完整对接**
