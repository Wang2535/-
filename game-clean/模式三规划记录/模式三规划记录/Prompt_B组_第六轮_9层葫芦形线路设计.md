# B组 - 第六轮：9层葫芦形分地图线路设计 Prompt

## 任务目标

基于A组定义的数据结构，为**全部9层**生成具体的葫芦形分地图数据。每层地图必须：
1. 呈**葫芦状**（上小下大的双圆+连接通道）
2. 符合设想中的**规则要求**（强连通、环路保证等）
3. **美观**（格子分布均衡、线路流畅自然）
4. 体现该层的**特殊机制**（通过地图结构体现）

> **边界说明**：
> - B组是**地图数据的唯一产出方**，负责调用A组的GourdLayoutGenerator工具库并手工微调，产出Layer1~Layer9的最终GourdMapTopology数据文件
> - A组的GourdLayoutGenerator仅提供坐标计算、SVG导出等辅助工具，不负责生成具体层数据
> - B组产出的GourdMapTopology是**裸拓扑**（格子+线路+区域效果，不含关卡分配），C组负责填充关卡数据
> - L7/L8的动态行为（格子偏移、概率坍缩）在B组仅定义**数据配置**（如mobility字段、probabilityStrength字段），运行时执行逻辑由D组负责

### 视觉风格要点

1. **外圈装饰边框**：黄白相间的棋盘格纹路，类似复古地图的经纬线标注
2. **内部填充**：根据层级主题的不同背景纹理（L1生物绿+病毒图案、L2赛博青+矩阵网格...）
3. **线路样式**：
   - 主路径：实线，宽度适中，颜色为主题色
   - 分支路径：稍细的实线或虚线
   - 特殊路径（回流/跨环）：特殊颜色（如红色回流、蓝色跨环）
4. **格子视觉**：
   - 圆角方形或六边形
   - 根据状态有不同边框和光效
   - 精英格有红色锯齿边框+骷髅图标

## 具体任务

### Task B3: 实现地图连通性验证器（语义级）

> **边界说明**：A组的 validateTopology() 负责**语法级验证**（字段完整性、ID唯一性、坐标范围），B组的 MapConnectivityValidator 负责**语义级验证**（强连通性、环路存在、Boss可达性、美观性）。两层验证互补，不重叠。

```typescript
// src/tower-mode/utils/mapValidator.ts
export class MapConnectivityValidator {
  /**
   * 语义级验证：强连通性——从任意格子可达其他所有格子
   */
  validateStrongConnectivity(topology: GourdMapTopology): boolean
  
  /**
   * 验证环路保证：至少存在一个≥4格的闭环
   */
  validateLoopExistence(topology: GourdMapTopology): boolean
  
  /**
   * 验证Boss格可达性
   */
  validateBossAccessibility(topology: GourdMapTopology): boolean
  
  /**
   * 计算平均路径长度
   */
  calculateAveragePathLength(topology: GourdMapTopology): number
  
  /**
   * 生成完整的验证报告
   */
  generateValidationReport(layer: number): ValidationReport
}
```

## 验收标准

1. ✅ 9层地图全部实现，每层数据完整
2. ✅ 所有地图呈葫芦形（可通过可视化验证）
3. ✅ 强连通性验证通过（从任意格可达任意格）
4. ✅ 至少包含1个≥4格的闭环路径
5. ✅ Boss格可达（可能需要先通关若干关卡格）
6. ✅ 区域效果正确分配
7. ✅ 该层特殊机制通过地图结构体现
8. ✅ 地图美观（格子分布均衡、线路流畅）

## 美观性检查清单

- [ ] 格子分布均匀，无过度拥挤或稀疏区域
- [ ] 线路交叉合理，不会造成视觉混乱
- [ ] 起点→Boss的主路径清晰可见
- [ ] 功能格（书店/技能/交流会）位置合理，不偏僻
- [ ] 区域效果覆盖范围与格子匹配
- [ ] 整体符合该层主题的视觉风格

## 数据所有权流转

```
B组产出（裸拓扑）           C组产出（富集拓扑）          D/E/F组消费
┌─────────────────┐      ┌──────────────────────┐     ┌───────────────┐
│ GourdMapTopology │ ───→ │ EnrichedTopology      │ ──→ │ D组: 引擎计算  │
│ (格子+线路+区域)  │      │ (格子+线路+区域+      │     │ E组: UI渲染    │
│                  │      │  关卡分配+Boss配置)   │     │ F组: 集成测试  │
└─────────────────┘      └──────────────────────┘     └───────────────┘
```

> ⚠️ B组产出的GourdMapTopology是**只读基础数据**，C组在其上扩展为EnrichedTopology。D/E/F组应从C组获取最终数据，不应直接修改B组的原始拓扑。
