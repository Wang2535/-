## 一、关卡格（Battle Cell）设计

### 1.1 功能描述

关卡格是爬塔地图中最核心的交互节点。玩家踩中后触发对应关卡对战，胜利后解锁该关卡并获得该关卡专属卡牌加入玩家卡池。

**核心定位**：
- 占每层格子总数的 **45%**（约4个/层）
- 玩家获取卡牌资源的主要途径
- 推进游戏进程的核心驱动力

### 1.3 奖励机制

| 奖励类型 | 获取条件 | 内容说明 |
|----------|----------|----------|
| **关卡解锁** | 战斗胜利 | 该关卡标记为已通关，可在图鉴中查看 |
| **专属卡牌** | 首次通关 | 该关卡对应的1张专属卡牌加入玩家可用卡池 |
| **经验值** | 战斗胜利 | `经验值 = 关卡编号 × 10` |
| **金币** | 战斗胜利 | `金币 = 关卡编号 × 5` |
| **额外稀有卡牌** | 20%概率 | 从稀有卡池随机抽取1张 |

**卡牌获取规则**：
- 每个关卡对应1张专属卡牌，主题与关卡内容一致
- 首次通关必得专属卡牌，重复通关不再获得
- 卡牌立即加入玩家可用卡池（非当前手牌组）

## 二、机会格（Chance Cell）设计

### 2.1 功能描述

机会格是爬塔地图中的随机事件节点。玩家踩中后从机会事件库中随机抽取一个事件并执行其效果，为游戏增加不确定性和策略趣味性。

**核心定位**：
- 占每层格子总数的 **20%**（约1-2个/层）
- 打破线性推进节奏的随机性来源
- 可能带来正面收益或负面风险

```typescript
/** 机会事件执行器 - 马甲函数预留接口 */
export class ChanceEventExecutor {
  /**
   * 执行机会事件
   * @param event 事件数据
   * @param selectedOptionId 玩家选择的选项ID
   * @param playerState 当前玩家状态
   * @returns 执行结果
   */
  async executeEvent(
    event: ChanceEvent,
    selectedOptionId: string,
    playerState: PlayerState
  ): Promise<ChanceEventResult> {
    const option = event.options.find(o => o.id === selectedOptionId);
    if (!option) throw new Error('Invalid option selected');

    const results: EffectResult[] = [];

    for (const effect of option.effects) {
      const result = await this.applyEffect(effect, playerState);
      results.push(result);
    }

    return {
      eventId: event.id,
      optionId: selectedOptionId,
      effects: results,
      timestamp: Date.now(),
    };
  }

  /**
   * 单个效果应用 - 马甲函数核心
   * 后续可在此扩展具体效果实现
   */
  private async applyEffect(
    effect: ChanceEventEffect,
    playerState: PlayerState
  ): Promise<EffectResult> {
    switch (effect.type) {
      case 'add_gold':
        return this.handleAddGold(effect, playerState);
      case 'remove_gold':
        return this.handleRemoveGold(effect, playerState);
      case 'add_card':
        return this.handleAddCard(effect, playerState);
      case 'heal':
        return this.handleHeal(effect, playerState);
      case 'damage':
        return this.handleDamage(effect, playerState);
      case 'modify_dice':
        return this.handleModifyDice(effect, playerState);
      default:
        return this.handleCustom(effect, playerState);
    }
  }
```

## 三、书店格（Bookstore Cell）设计

### 3.1 功能描述

书店格是爬塔地图中的学习节点。玩家踩中后进入书籍选择界面，从书籍库中随机抽取3本书籍供选择阅读。阅读后触发对应的知识增益效果。

**核心定位**：
- 占每层格子总数的 **10%**（约1个/层）
- 提供被动增益和知识积累
- 与网络安全学习主题深度结合

### 3.4 阅读效果触发逻辑

```typescript
/**
 * 书籍阅读效果触发器
 */
export class BookReadingExecutor {
  /**
   * 执行书籍阅读效果
   */
  async readBook(book: BookData, playerState: PlayerState): Promise<BookReadResult> {
    const appliedEffects: AppliedBookEffect[] = [];

    for (const effect of book.effects) {
      const result = await this.applyBookEffect(effect, playerState);
      appliedEffects.push(result);
    }

    return {
      bookId: book.id,
      bookName: book.name,
      effectsApplied: appliedEffects,
      readAt: Date.now(),
    };
  }

  private async applyBookEffect(
    effect: BookEffect,
    state: PlayerState
  ): Promise<AppliedBookEffect> {
    switch (effect.type) {
      case BookEffectType.BUFF_DEFENSE:
        return { ...effect, applied: true, currentValue: state.defense + (effect.value as number) };
      case BookEffectType.BUFF_ATTACK:
        return { ...effect, applied: true, currentValue: state.attack + (effect.value as number) };
      case BookEffectType.BUFF_HEALTH:
        return { ...effect, applied: true, currentValue: state.maxHealth + (effect.value as number) };
      case BookEffectType.SKILL_UNLOCK:
        return { ...effect, applied: true, unlockedSkillId: effect.value as string };
      case BookEffectType.KNOWLEDGE_POINT:
        return { ...effect, applied: true, knowledgeGained: effect.value as string };
      default:
        return { ...effect, applied: true };
    }
  }
}

export interface BookReadResult {
  bookId: string;
  bookName: string;
  effectsApplied: AppliedBookEffect[];
  readAt: number;
}

export interface AppliedBookEffect extends BookEffect {
  applied: boolean;
  currentValue?: number;
  unlockedSkillId?: string;
  knowledgeGained?: string;
}
```

## 四、Skill格（Skill Cell）设计

### 4.1 功能描述

Skill格是爬塔地图中的技能获取节点。玩家踩中后根据当前层级的概率表随机获得一个技能，技能分5个品质等级，玩家最多同时携带3个技能。

**核心定位**：
- 占每层格子总数的 **10%**（约1个/层）
- 核心Roguelike成长要素之一
- 策略搭配的关键变量

### 4.2 技能数据结构定义

## 五、End格（BOSS Cell）设计

### 5.1 功能描述

End格（BOSS格）是每层的最终挑战节点，位于每层地图的中心位置。玩家踩中后触发本层BOSS对战，BOSS由该层多余关卡中最强者改造而来。战胜BOSS后进入下一层（或游戏通关，若为第9层），并获得数据包奖励。

**核心定位**：
- 每层仅 **1个**，位于地图中心
- 层级进度的门槛
- 最高质量的奖励来源

### 5.2 BOSS关改造规则

```
┌─────────────────────────────────────────────────────────────────────┐
│                     BOSS改造规则                                    │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  【BOSS来源】                                                        │
│  每层主题有16个原始关卡（T1-T8）或15个（T9）                        │
│  每层使用其中9个作为常规关卡格                                      │
│  剩余 6-7 个关卡作为BOSS候选池                                      │
│                                                                     │
```
