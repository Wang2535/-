## 三、模块间接口契约

### 3.1 数据流向规范

```
[M04地图数据] ──提供──→ [M08移动系统] ──触发──→ [M06格子系统]
                                          │
[M05关卡分配] ──注入──→ [M04地图数据]        ├──→ [M07特殊区域]
                                          │
[M03工具函数] ──被调用──→ [M05/M06/M07/M08]  ├──→ [M09功能格执行]
                                          │
[M01/M02] ──被引用──→ [所有其他模块]         ├──→ [M10奖励系统]
                                          │
[M09/M10] ──回调──→ [M11进度管理]           └──→ [M11进度管理]
```

### 3.2 共享接口清单（由M01定义）

```
// ====== 核心类型（M01定义） ======

// 格子类型
type CellType = 'battle' | 'chance' | 'bookstore' | 'skill' | 'boss' | 'end';

// 特殊区域类型
type ZoneType = 'W' | 'N' | 'I' | 'P' | 'S' | 'D';

// 格子状态
type CellState = 'locked' | 'unlocked' | 'visited' | 'current' | 'pending';

// 格子数据接口
interface GameCell {
  id: string;
  coordinate: [number, number]; // [row, col]
  type: CellType;
  state: CellState;
  zone?: ZoneType;
  levelId?: string;       // 关卡ID（如果是战斗格）
  metadata?: Record<string, unknown>;
}

// 地图层数据接口
interface TowerLayerData {
  layerNumber: number;       // 1-9
  themeId: string;           // 主题标识
  shapeType: string;         // 造型类型
  cells: GameCell[];         // 所有格子
  paths: PathConnection[];   // 路径连接
  zones: ZoneDefinition[];   // 特殊区域
  startCellId: string;       // 起点格子ID
  bossCellId: string;        // Boss格子ID
  endCellId: string;         // 终点格子ID
}

// 路径连接
interface PathConnection {
  from: string;  // cellId
  to: string;    // cellId
  direction: 'bidirectional' | 'one-way';
  pathType: 'main' | 'shortcut';
}

// 特殊区域定义
interface ZoneDefinition {
  type: ZoneType;
  cellIds: string[];
  effect: ZoneEffectConfig;
  visualConfig: ZoneVisualConfig;
}
```

### 3.3 事件总线接口（模块间通信）

```
// ====== 事件总线事件类型 ======
type TowerEventType =
  | { type: 'CELL_ENTER'; cellId: string; playerPos: [number,number] }
  | { type: 'CELL_TRIGGER'; cellId: string; cellType: CellType }
  | { type: 'ZONE_ENTERED'; zoneType: ZoneType; effectApplied: boolean }
  | { type: 'MOVE_COMPLETE'; from: string; to: string; diceResult: number }
  | { type: 'BATTLE_START'; levelId: string; cellId: string }
  | { type: 'BATTLE_END'; victory: boolean; rewards: Reward[] }
  | { type: 'BOSS_DEFEATED'; layerNumber: number; dataPackets: DataPacket[] }
  | { type: 'SKILL_ACQUIRED'; skill: Skill; replacedSkill?: Skill }
  | { type: 'BOOK_READ'; book: Book; effectApplied: boolean }
  | { type: 'CHANCE_EVENT'; event: ChanceEvent; result: EventResult }
  | { type: 'DATA_PACKET_SELECTED'; packet: DataPacket }
  | { type: 'LAYER_COMPLETE'; layerNumber: number }
  | { type: 'GAME_COMPLETE'; finalStats: GameStats };
```

## 五、各模块独立开发检查清单

每个模块必须满足以下条件才算"开发完成"：

### 代码层面
- [ ] 所有TypeScript类型导出自 `tower-mode/types/`
- [ ] 所有常量导出自 `tower-mode/constants/`
- [ ] 所有函数有完整的 JSDoc 注释
- [ ] 导出清晰的公共 API 接口
- [ ] 不直接依赖其他模块的实现细节（只依赖类型和接口）

### 测试层面
- [ ] 单元测试覆盖核心逻辑（目标 ≥80%）
- [ ] Mock 其他模块的依赖
- [ ] 边界条件测试（空输入/异常值）
- [ ] 集成测试模板（与其他模块联调时使用）

### 文档层面
- [ ] 模块内部 README（说明职责/用法/API）
- [ ] 接口文档（输入/输出/副作用）
- [ ] 与其他模块的依赖说明
