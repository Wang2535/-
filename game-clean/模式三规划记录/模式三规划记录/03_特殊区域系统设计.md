# 特殊区域系统设计

> 安全实践爬塔模式 - 地图特殊区域效果系统设计文档
> 参考海幸地图中的W/N/I/P等区域标记概念

---

## 一、系统概述

### 1.1 特殊区域的概念

**特殊区域**是指在地图中划定的一片连续格子范围，区域内任意格子被玩家踩中时，会自动触发特定的效果。特殊区域独立于功能格子存在，两者效果可以叠加触发。

**核心特征：**
- **空间连续性**：区域由相邻的多个格子组成，形成连续的空间范围
- **自动触发**：玩家进入区域内任意格子时，立即触发区域效果
- **效果叠加**：区域效果与格子自身的功能效果叠加生效
- **视觉标识**：通过颜色、图标等视觉元素清晰标识区域类型

### 1.2 设计目的

1. **增加策略深度**：玩家需要权衡路线选择，是冒险穿越危险区域还是绕行安全路径
2. **丰富游戏体验**：通过区域效果创造更多变数和惊喜，避免单调的移动机制
3. **强化主题表达**：不同区域类型对应不同的安全主题，增强沉浸感
4. **平衡风险收益**：高风险区域往往伴随高收益，考验玩家的决策能力

### 1.3 与功能格子的关系

| 对比维度 | 特殊区域 | 功能格子 |
|---------|---------|---------|
| 触发方式 | 进入区域内任意格子自动触发 | 踩中特定格子触发 |
| 作用范围 | 多个连续格子 | 单个格子 |
| 效果类型 | 状态改变、资源变化、地图变换 | 卡牌获取、商店、休息等 |
| 叠加规则 | 与格子效果叠加触发 | 独立触发 |
| 视觉呈现 | 半透明覆盖层 + 图标 | 格子背景色 + 功能图标 |

**叠加规则：**
- 玩家踩中同时属于特殊区域和功能格子的格子时，先触发区域效果，再触发格子效果
- 区域效果和格子效果独立计算，互不干扰
- 某些特殊区域效果可能影响后续格子效果的触发（如P区域跳过回合）

## 二、已确定区域效果详细设计

### 2.1 W区域（Weakness/虚弱区）

#### 基础信息
| 属性 | 值 |
|-----|-----|
| 区域代码 | W |
| 中文名称 | 虚弱区 |
| 英文名称 | Weakness Zone |
| 效果类型 | 负面状态 |
| 触发时机 | 进入区域内任意格子时 |

#### 效果描述
踩中W区域后，玩家下次投掷骰子的点数-1（最低为1）。

#### 视觉标识
- **颜色**：淡红色半透明覆盖（RGBA: 255, 100, 100, 0.3）
- **图标**：向下箭头或虚弱符号
- **动画**：进入时红色波纹扩散效果

#### 适用场景
- 危险区域边缘（如Boss房间外围）
- 陷阱区周边
- 需要玩家谨慎选择的路径

#### 策略提示
> "经过此区域会削弱你的行动力，下次投掷点数-1"

#### 技术实现要点
```typescript
// 伪代码示例
interface WeaknessZone {
  type: 'W';
  effect: {
    diceModifier: -1;
    duration: 1; // 持续1次投掷
  };
  visual: {
    color: 'rgba(255, 100, 100, 0.3)';
    icon: 'weakness';
  };
}
```

### 2.3 I区域（Invert/反转区）

#### 基础信息
| 属性 | 值 |
|-----|-----|
| 区域代码 | I |
| 中文名称 | 反转区 |
| 英文名称 | Invert Zone |
| 效果类型 | 地图变换 |
| 触发时机 | 进入区域内任意格子时 |

#### 效果描述
踩中I区域后，整张地图倒置（起点变为终点，终点变为起点），玩家位置保持不变但方向改变。

#### 视觉标识
- **颜色**：淡紫色半透明覆盖（RGBA: 200, 100, 255, 0.3）
- **图标**：旋转箭头图标
- **动画**：进入时地图旋转180度动画

#### 适用场景
- 迷宫中心
- 传送门附近
- 需要改变策略的转折点

#### 策略提示
> "此区域蕴含未知力量，可能改变一切"

#### 特殊限制
- 每个I区域只能触发一次
- 整局游戏限触发N次（建议3次）
- 触发后该区域变为普通区域

#### 技术实现要点
```typescript
// 伪代码示例
interface InvertZone {
  type: 'I';
  effect: {
    action: 'invertMap';
    triggersPerGame: 3;
    triggersPerZone: 1;
  };
  visual: {
    color: 'rgba(200, 100, 255, 0.3)';
    icon: 'rotate';
  };
  state: {
    triggeredCount: 0;
    isActive: true;
  };
}
```

## 三、区域范围划定方法

### 3.1 坐标范围法

使用左上角和右下角坐标定义矩形区域。

```typescript
interface CoordinateZone {
  type: 'rectangle';
  topLeft: { x: number; y: number };
  bottomRight: { x: number; y: number };
  zoneType: 'W' | 'N' | 'I' | 'P' | 'S' | 'D';
}

// 示例：定义一个W区域
const weaknessZone: CoordinateZone = {
  type: 'rectangle',
  topLeft: { x: 2, y: 3 },
  bottomRight: { x: 5, y: 6 },
  zoneType: 'W'
};
```

**优点：**
- 简单直观
- 易于计算
- 适合规则形状

**缺点：**
- 无法定义不规则形状
- 可能包含不需要的格子

### 3.2 形状定义法

支持多种形状：矩形、圆形、多边形。

```typescript
type ZoneShape = 'rectangle' | 'circle' | 'polygon';

interface ShapeZone {
  shape: ZoneShape;
  params: {
    // 矩形
    rectangle?: {
      topLeft: { x: number; y: number };
      bottomRight: { x: number; y: number };
    };
    // 圆形
    circle?: {
      center: { x: number; y: number };
      radius: number;
    };
    // 多边形
    polygon?: {
      points: Array<{ x: number; y: number }>;
    };
  };
  zoneType: 'W' | 'N' | 'I' | 'P' | 'S' | 'D';
}

// 示例：定义一个圆形N区域
const knowledgeZone: ShapeZone = {
  shape: 'circle',
  params: {
    circle: {
      center: { x: 4, y: 4 },
      radius: 2
    }
  },
  zoneType: 'N'
};
```

**优点：**
- 支持多种形状
- 更灵活
- 可以定义复杂区域

**缺点：**
- 计算复杂度较高
- 需要更复杂的碰撞检测

### 3.3 格子列表法

直接列出属于该区域的所有格子坐标。

```typescript
interface GridListZone {
  type: 'gridList';
  grids: Array<{ x: number; y: number }>;
  zoneType: 'W' | 'N' | 'I' | 'P' | 'S' | 'D';
}

// 示例：定义一个不规则I区域
const invertZone: GridListZone = {
  type: 'gridList',
  grids: [
    { x: 3, y: 3 },
    { x: 3, y: 4 },
    { x: 4, y: 4 },
    { x: 4, y: 5 },
    { x: 5, y: 5 }
  ],
  zoneType: 'I'
};
```

**优点：**
- 完全精确
- 支持任意形状
- 易于编辑

**缺点：**
- 数据量大
- 不够直观

## 四、区域效果叠加与冲突处理

### 4.1 同一格子属于多个区域

当一个格子同时属于多个区域时，需要定义优先级和触发规则。

#### 优先级规则

| 优先级 | 区域类型 | 说明 |
|-------|---------|------|
| 1（最高） | I区域 | 反转区优先级最高，立即触发 |
| 2 | D区域 | 危险区次之，优先触发惩罚 |
| 3 | P区域 | 跳过区第三 |
| 4 | W区域 | 虚弱区第四 |
| 5 | S区域 | 加速区第五 |
| 6（最低） | N区域 | 知识区优先级最低 |

#### 触发规则

```typescript
interface ZoneTriggerRule {
  // 按优先级排序触发
  triggerOrder: 'priority' | 'simultaneous';
  
  // 是否允许效果叠加
  allowStacking: boolean;
  
  // 叠加规则
  stackingRule: {
    // 正面效果可以叠加
    positiveEffects: 'stack';
    // 负面效果取最严重
    negativeEffects: 'worst';
    // 混合效果按优先级
    mixedEffects: 'priority';
  };
}

// 示例：一个格子同时属于W区域和S区域
const multiZoneGrid = {
  position: { x: 4, y: 4 },
  zones: ['W', 'S'],
  // 触发顺序：先触发S（正面），再触发W（负面）
  // 最终效果：额外投掷一次，但下次投掷点数-1
};
```

### 4.2 效果叠加还是只触发最高优先级

#### 方案A：按优先级触发（推荐）

**规则：**
- 按优先级从高到低依次触发各区域效果
- 所有效果都会生效（除非有特殊限制）
- 适用于大多数情况

**示例：**
```
格子同时属于W区域和S区域：
1. 先触发S区域：额外投掷一次骰子
2. 再触发W区域：下次投掷点数-1
最终效果：玩家获得额外投掷机会，但下次投掷会受影响
```

#### 方案B：只触发最高优先级

**规则：**
- 只触发优先级最高的区域效果
- 其他区域效果被忽略
- 适用于需要简化规则的情况

**示例：**
```
格子同时属于W区域和S区域：
1. 检测到两个区域
2. S区域优先级高于W区域
3. 只触发S区域效果
最终效果：玩家获得额外投掷机会，不受W区域影响
```

### 7.2 效果触发流程

```typescript
class ZoneEffectManager {
  // 检查格子是否在区域内
  checkZone(grid: GridPosition): Zone[] {
    const zoneIds = this.gridToZones.get(`${grid.x},${grid.y}`) || [];
    return zoneIds.map(id => this.zones.get(id)!);
  }
  
  // 触发区域效果
  async triggerZones(grid: GridPosition, player: Player): Promise<void> {
    const zones = this.checkZone(grid);
    
    // 按优先级排序
    zones.sort((a, b) => b.effect.priority - a.effect.priority);
    
    // 依次触发
    for (const zone of zones) {
      await this.triggerZone(zone, player);
    }
  }
  
  // 触发单个区域效果
  private async triggerZone(zone: Zone, player: Player): Promise<void> {
    // 检查冷却
    if (zone.state.triggered && zone.effect.cooldown) {
      return;
    }
    
    // 检查免疫
    if (player.hasImmunity(zone.type)) {
      return;
    }
    
    // 执行效果
    await this.executeEffect(zone.effect.action, player);
    
    // 更新状态
    zone.state.triggered = true;
    zone.state.triggerCount++;
    zone.state.lastTriggerTime = Date.now();
    
    // 触发UI反馈
    this.renderer.showFeedback(zone);
  }
  
  // 执行具体效果
  private async executeEffect(action: ZoneAction, player: Player): Promise<void> {
    switch (action.type) {
      case 'diceModifier':
        player.applyDiceModifier(action.value, action.duration);
        break;
      case 'reward':
        player.addReward(action.reward);
        break;
      case 'invertMap':
        await this.game.invertMap();
        break;
      case 'skipTurn':
        player.skipNextTurn();
        break;
      case 'extraDiceRoll':
        player.grantExtraDiceRoll();
        break;
      case 'penalty':
        player.applyPenalty(action.penalty);
        break;
    }
  }
}
```

### 7.3 UI渲染实现

```typescript
class ZoneRenderer {
  // 渲染区域覆盖层
  renderZones(canvas: HTMLCanvasElement, zones: Zone[]): void {
    const ctx = canvas.getContext('2d')!;
    
    for (const zone of zones) {
      // 设置样式
      ctx.fillStyle = zone.visual.color;
      ctx.globalAlpha = zone.visual.opacity;
      
      // 绘制区域形状
      this.drawZoneShape(ctx, zone);
      
      // 绘制图标
      this.drawZoneIcon(ctx, zone);
    }
    
    ctx.globalAlpha = 1.0;
  }
  
  // 绘制区域形状
  private drawZoneShape(ctx: CanvasRenderingContext2D, zone: Zone): void {
    switch (zone.shape.type) {
      case 'rectangle':
        this.drawRectangle(ctx, zone);
        break;
      case 'circle':
        this.drawCircle(ctx, zone);
        break;
      case 'polygon':
        this.drawPolygon(ctx, zone);
        break;
    }
  }
  
  // 绘制矩形区域
  private drawRectangle(ctx: CanvasRenderingContext2D, zone: Zone): void {
    const { topLeft, bottomRight } = zone.shape.params.rectangle!;
    const width = bottomRight.x - topLeft.x + 1;
    const height = bottomRight.y - topLeft.y + 1;
    
    ctx.fillRect(
      topLeft.x * GRID_SIZE,
      topLeft.y * GRID_SIZE,
      width * GRID_SIZE,
      height * GRID_SIZE
    );
  }
  
  // 显示反馈效果
  showFeedback(zone: Zone): void {
    // 显示动画
    this.playAnimation(zone.visual.animation);
    
    // 显示提示
    this.showTooltip(zone);
    
    // 播放音效
    this.playSound(zone.type);
  }
  
  // 播放动画
  private playAnimation(animationName: string): void {
    const animation = this.animations.get(animationName);
    if (animation) {
      animation.play();
    }
  }
  
  // 显示提示
  private showTooltip(zone: Zone): void {
    const tooltip = this.createTooltip(zone);
    document.body.appendChild(tooltip);
    
    setTimeout(() => {
      tooltip.remove();
    }, 2000);
  }
  
  // 播放音效
  private playSound(zoneType: string): void {
    const soundId = this.getSoundId(zoneType);
    this.audioManager.play(soundId);
  }
```
