# 视觉回归测试清单

## 概述
本文档记录爬塔模式(TowerMode)各UI组件的视觉验收标准，用于手动或自动化视觉回归验证。

## 1. TowerMapView 地图视图

### 布局
- [ ] 地图容器占据主内容区域全部空间
- [ ] 空状态显示"等待地图数据加载..."居中提示
- [ ] 有格子数据时，每个格子以60x60px方块渲染
- [ ] 格子间距合理，无重叠
- [ ] 玩家标记(🧙)以圆形蓝色发光样式显示在当前位置

### 格子视觉
- [ ] 战斗格(⚔️) 显示红色/橙色边框暗示
- [ ] 机会格(❓) 显示黄色边框
- [ ] 书店格(📚) 显示蓝色边框
- [ ] Skill格(⚡) 显示紫色边框
- [ ] BOSS格(👑) 显示金色边框
- [ ] 终点格(🚪) 显示白色/银色边框
- [ ] 可达格子有半透明高亮背景
- [ ] 不可达格子降低透明度

## 2. TowerHUD 顶部信息栏

### 布局
- [ ] 固定在顶部，高度约48px
- [ ] 左侧信息（层数/HP/道具）左对齐
- [ ] 右侧技能+菜单按钮右对齐
- [ ] 底部有分隔线

### 数据展示
- [ ] 层数显示为"🏰 第 N 层"金色文字
- [ ] HP条：满血绿色，中血黄色，低血红色
- [ ] HP数值格式 "当前/最大"
- [ ] 数据包📦数量正确
- [ ] 书籍📖数量正确
- [ ] 移动👣次数正确
- [ ] 技能标签以半透明紫色背景展示

## 3. MovementControl 移动控制面板

### 布局
- [ ] 固定在底部，高度约72px
- [ ] 左侧骰子区域 + 骰子结果
- [ ] 右侧移动选项列表（可横向滚动）

### 交互状态
- [ ] 骰子按钮：可用时蓝色渐变+发光边框
- [ ] 骰子按钮：禁用时灰色+不可点击光标
- [ ] 骰子图标大小合适（🎲）
- [ ] 骰子结果显示为蓝底数字
- [ ] 移动选项按钮：推荐选项有⭐标记
- [ ] 无选项时显示"投掷骰子以查看可移动位置"灰色提示

## 5. 响应式布局

- [ ] 1920x1080：所有元素正常显示，无溢出
- [ ] 1366x768：HUD和Control栏正常，地图区域自适应
- [ ] 弹窗在所有分辨率下居中且不溢出屏幕

## 6. 动画与过渡

- [ ] 弹窗出现：淡入效果 ~200ms
- [ ] LayerTransition：阶梯式淡入（图标→标题→预览→按钮）
- [ ] 通知出现：slideIn从右侧滑入
- [ ] HP条变化：width过渡 ~300ms
- [ ] 所有动画使用 transform/opacity 而非 layout 属性（避免重排）

## 7. 无障碍性（基础）

- [ ] 所有交互元素可通过键盘Tab访问
- [ ] 按钮 focus 时有可见的focus ring
- [ ] 颜色对比度符合 WCAG AA 标准（正文与背景比 ≥ 4.5:1）
