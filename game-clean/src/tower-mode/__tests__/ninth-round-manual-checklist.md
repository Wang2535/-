# F组第九轮：手动验证清单（64项）

启动服务器 (`npm run dev`) 后，打开爬塔模式，逐项检查：

## 一、视觉验证（20项）

### 1.1 葫芦形地图（6项）
- [ ] 地图整体呈葫芦形（上小下大）
- [ ] 上圆半径约为下圆的50-60%
- [ ] 连接通道自然收腰过渡
- [ ] 棋盘格边框沿葫芦轮廓分布
- [ ] 十字分割线清晰可见
- [ ] W/N/I/P 四象限标签大而醒目

### 1.2 格子渲染（7项）
- [ ] Boss格明显比普通格大（2.5倍）
- [ ] Boss格有红色脉动光环
- [ ] 精英格有锯齿虚线边框
- [ ] 不同类型格子形状不同（圆/六角/菱形等）
- [ ] 锁定格灰暗半透明
- [ ] 当前格有绿色发光效果
- [ ] 待处理格有橙色脉冲

### 1.3 线路与背景（7项）
- [ ] 格子间连线为平滑曲线
- [ ] 主线白色，支线灰色虚线
- [ ] 背景有深色渐变
- [ ] 上圆中央有星球装饰
- [ ] 装饰元素有微浮动动画
- [ ] 象限标签颜色正确（W/P橙，N/I黄）
- [ ] 象限标签有白色描边和阴影

## 二、交互验证（12项）

### 2.1 玩家棋子（5项）
- [ ] 玩家棋子可见（绿色圆形）
- [ ] 棋子有缓慢呼吸动画
- [ ] 移动时显示轨迹光痕
- [ ] 到达新格子有扩散波纹
- [ ] 棋子有发光效果

### 2.2 操作交互（4项）
- [ ] 点击骰子按钮可掷骰
- [ ] 骰子结果1-6范围
- [ ] 点击可移动格子触发移动
- [ ] 移动后触发格子交互

### 2.3 弹窗交互（3项）
- [ ] 战斗弹窗正确弹出
- [ ] 书店/技能弹窗可交互
- [ ] 弹窗关闭后状态正确

## 三、区域效果验证（8项）

### 3.1 W区域（弱点区）（2项）
- [ ] 进入W区域触发弱点效果
- [ ] W区域视觉标识可见

### 3.2 N区域（知识区）（2项）
- [ ] 进入N区域触发知识效果
- [ ] N区域视觉标识可见

### 3.3 I区域（反转区）（2项）
- [ ] 进入I区域触发反转效果
- [ ] I区域视觉标识可见

### 3.4 P区域（跳过区）（2项）
- [ ] 进入P区域触发跳过效果
- [ ] P区域视觉标识可见

## 四、层级差异化验证（6项）

- [ ] L1-L9 每层拓扑形状不同
- [ ] L1-L9 每层格子数量不同
- [ ] L1-L9 每层象限效果组合不同
- [ ] 切换层级时地图正确更新
- [ ] 层级过渡动画流畅
- [ ] 9层全部可访问

## 五、游戏机制验证（14项）

### 5.1 骰子系统（3项）
- [ ] 掷骰子返回1-6的结果
- [ ] 连续掷骰结果有变化
- [ ] 骰子结果影响可移动步数

### 5.2 战斗系统（3项）
- [ ] 进入战斗格触发战斗
- [ ] 战斗胜利获得奖励
- [ ] 战斗失败扣除技术值

### 5.3 资源系统（3项）
- [ ] 技术值随战斗变化
- [ ] 技术值达到里程碑触发奖励
- [ ] 技术值归零触发游戏结束

### 5.4 进度系统（3项）
- [ ] 击败Boss推进层级
- [ ] 存档功能正常工作
- [ ] 读档恢复游戏状态

### 5.5 地图翻转（2项）
- [ ] 快速到达终点触发翻转
- [ ] 翻转后地图方向倒置

## 六、性能验证（4项）

- [ ] 地图渲染无明显卡顿（<250ms）
- [ ] 切换层级无白屏闪烁
- [ ] 连续操作10次无内存泄漏
- [ ] 控制台无红色错误
