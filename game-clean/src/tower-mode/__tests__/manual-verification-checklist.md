# F组第八轮：手动验证清单（40项）

启动服务器 (`npm run dev`) 后，打开爬塔模式，逐项检查：

## 一、整体布局（4项）P0

- [ ] 地图为**葫芦形**（上小圆+连接+下大圆），非矩形网格
- [ ] 比例协调（上圆直径约为下圆的50~60%）
- [ ] 连接通道自然过渡（上下圆之间有收腰）
- [ ] 页面加载后2秒内地图完整显示

## 二、象限标识 W/N/I/P（6项）P0 ★★★

- [ ] 四个字母**非常大且醒目**（一眼就能看到！）
- [ ] 字体为**粗黑体**（fontWeight: 900）
- [ ] W/P 为**橙红色** #FF8800，N/I 为**金黄色** #FFCC00
- [ ] 有**白色描边**（strokeColor: #FFFFFF）
- [ ] 有**阴影效果**（shadowColor: #000000）
- [ ] 十字分割线清晰可见

## 三、棋盘格边框（5项）P0 ★★★

- [ ] 是**实心方格交替填充**图案（mode: checkerboard-fill）
- [ ] 配色为**橙黄白**交替（#FFAA00, #FFFFFF）
- [ ] 方格沿葫芦形轮廓分布
- [ ] 整体有一定透明度（能隐约看到内部内容）
- [ ] 外围有轻微发光效果

## 四、功能格子系统（7项）P0/P1 ★★★

- [ ] 格子沿葫芦轮廓**自然分布**
- [ ] **Boss格明显比普通格大很多**（sizeMultiplier: 2.5）
- [ ] Boss格有**红色脉动光环动画**（animationClass: gm-boss-emerge）
- [ ] 精英格有**锯齿状虚线边框+抖动**
- [ ] 格子使用**矢量风格图标**（icon.type: letter/svg）
- [ ] 不同类型格子形状不同（圆/六角/菱形/方等）
- [ ] 锁定格灰暗半透明（opacity: 0.4），待处理格橙色闪烁

## 五、线路系统（3项）P1

- [ ] 格子间连线为**平滑曲线**（贝塞尔曲线）
- [ ] 主线颜色为白色（#ffffff）
- [ ] 支线/回程线用不同颜色或虚线区分

## 六、玩家棋子与动画（7项）P0 ★★★

- [ ] **玩家棋子可见**（绿色圆形+🎮图标）
- [ ] 棋子有**缓慢呼吸动画**（gm-piece-breathe，周期约2秒）
- [ ] 移动时显示**轨迹光痕**（渐隐的绿色光点）
- [ ] 到达新格子时有**扩散波纹**（gm-arrival-ripple）
- [ ] 移动过程流畅（CSS transition: 0.15s）
- [ ] 棋子有发光效果（boxShadow: #44ff88）
- [ ] 进入W/N/I/P区域时对应区域特效触发

## 七、背景装饰（4项）P2

- [ ] 上圆中央有**星球装饰**（type: planet）
- [ ] 背景有**深色渐变**（非纯色）
- [ ] 有**云朵/粒子/数据流**等点缀装饰
- [ ] 装饰元素有**微浮动动画**

## 八、层级切换（3项）P0

- [ ] 点击可切换L1~L9
- [ ] 每层布局/主题色不同
- [ ] 切换时无明显闪烁/白屏

## 九、性能体验（3项）P1

- [ ] 切换层级卡顿 < 250ms
- [ ] 无明显内存泄漏（切换10次后仍流畅）
- [ ] 控制台无红色错误

## 验收标准

- P0 项目必须全部通过
- P1 项目 ≥80% 通过
- P2 项目 ≥50% 通过
- 总体 ≥35/40 项通过
