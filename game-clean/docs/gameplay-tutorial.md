## 一、游戏基础玩法

### 1.1 游戏概述

#### 游戏背景

《大东话安全》是一款基于中国科学院计算技术研究所《大东话安全》科普文章改编的网络安全教育卡牌游戏。玩家将扮演网络安全专家，与大东AI一起对抗各种网络威胁，学习网络安全知识。

#### 游戏目标

在每个关卡中，玩家需要：
- **清除威胁**：移除所有敌方攻击标记
- **保护系统**：维持安全等级不低于0
- **控制区域**：在关键区域建立防御优势

#### 胜利条件

每个关卡有特定的胜利条件，常见类型包括：
1. **清除病毒**：移除所有敌方标记
2. **全面接种**：在所有区域建立防御优势
3. **系统重写**：达成特定的战术目标

#### 失败条件

1. **安全等级归零**：安全等级降至0
2. **全面感染**：敌方标记总数超过阈值
3. **回合超限**：超过最大回合数（通常是10-12轮）

### 1.2 回合制机制

#### 阶段、回合、轮次关系

#### 阶段详解

每个角色的回合包含七个阶段，按顺序执行：

##### 阶段1：判定阶段
- **触发时机**：回合开始时首先执行
- **执行动作**：
  - 检查并处理持续性效果（如中毒、增益等状态）
  - 执行需要在本回合开始时触发的技能判定
  - 检查区域特性对当前角色的影响
  - 处理延迟类效果的触发（如潜伏标记转化）
- **特殊说明**：某些卡牌和技能会在此阶段产生效果

##### 阶段2：恢复阶段
- **触发时机**：判定阶段之后
- **执行动作**：
  - 恢复行动点至上限（玩家5点，大东3点，敌人根据配置）
  - 恢复基础资源（算力、资金、信息各+1）
  - 清除临时性负面状态（如"下回合行动点-2"）
  - 触发"回合开始时恢复"类技能效果
- **注意**：安全等级和渗透等级不会自动恢复

##### 阶段3：摸牌阶段
- **触发时机**：恢复阶段之后
- **执行动作**：
  - 从牌库抽取固定数量卡牌（通常为2张）
  - 检查手牌上限（超出需弃牌）
  - 触发"摸牌时"类技能效果
- **特殊规则**：
  - 牌库为空时，将弃牌堆洗牌形成新牌库
  - 某些技能可以修改摸牌数量

##### 阶段4：行动阶段
- **触发时机**：摸牌阶段之后，是回合的核心阶段
- **可执行操作**：
  - **放置标记**：在所在区域放置防御/攻击标记（消耗行动点）
  - **使用卡牌**：打出卡牌执行效果（消耗行动点+资源）
  - **移动区域**：移动到其他区域（消耗1行动点）
  - **使用技能**：触发角色特殊技能（消耗行动点）
  - **结束回合**：提前结束行动阶段
- **限制条件**：
  - 行动点耗尽时自动结束
  - 某些状态可能限制可执行的操作

##### 阶段5：响应阶段
- **触发时机**：行动阶段结束后
- **执行动作**：
  - 检查是否有可触发的响应类效果
  - 处理其他角色对当前角色行动的响应
  - 执行陷阱、伏击等响应式卡牌效果
  - 触发"行动结束后"类技能效果
- **特殊说明**：响应阶段可以打出特定的响应类卡牌

##### 阶段6：弃牌阶段
- **触发时机**：响应阶段之后
- **执行动作**：
  - 检查手牌是否超过上限（通常为3张）
  - 超出上限时选择卡牌弃置到弃牌堆
  - 触发"弃牌时"类技能效果
- **策略提示**：合理规划手牌，避免被迫弃掉关键卡牌

##### 阶段7：结束阶段
- **触发时机**：弃牌阶段之后，回合最后阶段
- **执行动作**：
  - 触发"回合结束时"类技能效果
  - 清除本回合的临时性增益效果
  - 更新回合计数器
  - 检查胜利/失败条件（仅在特定回合结束时）
- **过渡**：当前回合结束，进入下一个角色的回合

#### 轮次计算规则

```
轮次 = ⌈当前回合数 / 4⌉

示例：
- 第1-4回合 = 第1轮（玩家→大东→敌人1→敌人2）
- 第5-8回合 = 第2轮（玩家→大东→敌人1→敌人2）
- 第9-12回合 = 第3轮（玩家→大东→敌人1→敌人2）

轮次与回合对应关系：
┌─────────┬─────────┬─────────┬─────────┐
│  轮次   │ 玩家回合 │ 大东回合 │ 敌人回合 │
├─────────┼─────────┼─────────┼─────────┤
│ 第1轮   │  第1回合 │  第2回合 │ 3-4回合 │
│ 第2轮   │  第5回合 │  第6回合 │ 7-8回合 │
│ 第3轮   │  第9回合 │ 第10回合 │ 11-12   │
└─────────┴─────────┴─────────┴─────────┘
```

**重要提示**：
- 部分技能和卡牌效果按"轮次"计算，而非"回合"
- 每轮次开始时，某些全局效果会重置或触发
- 轮次限制是游戏失败条件之一

### 1.3 资源系统

#### 五种核心资源

| 资源图标 | 资源名称 | 作用 | 获取方式 |
|:-------:|:-------:|:----:|:-------:|
| ⚡ | 算力 | 执行技术操作 | 每回合自动恢复、卡牌效果 |
| 💰 | 资金 | 购买/使用资源 | 每回合自动恢复、卡牌效果 |
| 📊 | 信息 | 情报收集、分析 | 每回合自动恢复、卡牌效果 |
| 🛡️ | 安全等级 | 绑定游戏科技树、胜利与失败条件 | 特定卡牌增加 |
| 🔴 | 渗透等级 | 绑定游戏科技树、胜利与失败条件 | 特定卡牌增加 |

#### 资源管理策略

##### 算力管理
- **用途**：使用技术类卡牌、执行复杂操作
- **策略**：优先保留算力用于关键卡牌的释放

##### 资金管理
- **用途**：使用商业类卡牌、购买资源
- **策略**：合理分配资金，避免关键时刻资金不足

##### 信息管理
- **用途**：使用情报类卡牌、增强判定成功率
- **策略**：与其他资源搭配好，如资金、算力等，以获得更好的效果

##### 安全等级管理

**安全等级的作用**：

安全等级是防御方的核心资源，代表系统的安全状态：

- **科技树绑定**：安全等级决定防御方可使用的卡牌科技等级
  - 安全等级 5：解锁T1科技，获得基础防御卡牌和效果
  - 安全等级 15：解锁T2科技，获得进阶防御卡牌和效果
  - 安全等级 30：解锁T3科技，获得高级防御卡牌和效果
  - 安全等级 40：解锁T4科技，获得专家级防御卡牌和效果
  - 安全等级 50：解锁T5科技，获得大师级防御卡牌和效果
- **肉鸽选择**：T1-T4解锁时会触发肉鸽选择（3选1），选择不同的强化方向
- **胜利条件**：达到75级并持续2回合触发胜利条件
- **失败条件**：安全等级降至0时，防御失败，游戏结束

**恢复方式**：
- 使用防御类卡牌（如"系统修复"、"备份恢复"）
- 大东AI的支援技能
- 成功防御敌人攻击
- 控制关键区域获得安全等级奖励

**管理策略**：
- **维持高位**：保持安全等级在50以上，确保T2卡牌可用
- **预留恢复**：保留恢复类卡牌应对紧急情况
- **预防优先**：在敌人攻击前使用防御卡牌预防
- **权衡取舍**：在安全等级低时，优先恢复而非进攻

##### 渗透等级管理

**渗透等级的作用**：

渗透等级是攻击方（敌人）的核心资源，代表对系统的渗透程度：

- **科技树绑定**：渗透等级决定攻击方可使用的卡牌科技等级
  - 渗透等级 5：解锁T1科技，获得基础攻击卡牌和效果
  - 渗透等级 15：解锁T2科技，获得进阶攻击卡牌和效果
  - 渗透等级 30：解锁T3科技，获得高级攻击卡牌和效果
  - 渗透等级 40：解锁T4科技，获得专家级攻击卡牌和效果
  - 渗透等级 50：解锁T5科技，获得大师级攻击卡牌和效果
- **肉鸽选择**：T1-T4解锁时会触发肉鸽选择（3选1），选择不同的强化方向
- **胜利条件**：达到75级并持续2回合触发胜利条件
- **对防御方的影响**：高渗透等级会增强敌人的攻击力和技能效果

**增加方式**：
- 敌人成功放置攻击标记（+5渗透等级/标记）
- 敌人攻击卡牌效果
- 敌人技能触发
- 防御方安全等级下降时（渗透等级相应上升）

**控制策略**：
- **及时清理**：快速清理敌方标记，阻止渗透等级增长
- **打断节奏**：使用控制类卡牌打断敌人攻击
- **压制增长**：在安全等级高时主动进攻，压制敌人
- **监控预警**：关注渗透等级趋势，提前采取防御措施

#### 判定触发条件

1. **卡牌效果触发**：使用判定类卡牌时
2. **技能效果触发**：敌人/友方技能需要判定时
3. **区域控制触发**：特定区域状态变化时
4. **玩家主动触发**：玩家选择使用判定能力时

#### 判定执行顺序

1. **确定判定类型**：攻击判定、防御判定、技能判定
2. **确定判定难度**：根据卡牌/技能确定目标值（通常为4-6）
3. **掷骰子**：投掷1个6面骰（1-6点）
4. **计算结果**：骰子点数 vs 目标值
5. **应用效果**：根据判定结果执行相应效果

### 2.2 骰子判定机制

#### 判定规则详解

**基本判定流程**：

```
┌─────────────────────────────────────────────────────────────┐
│                      判定执行流程                            │
└─────────────────────────────────────────────────────────────┘

    触发判定
         │
         ▼
    ┌─────────────────┐
    │ 1. 确定判定类型  │
    │    - 攻击判定    │
    │    - 防御判定    │
    │    - 技能判定    │
    └─────────────────┘
         │
         ▼
    ┌─────────────────┐
    │ 2. 确定基础难度  │
    │    - 查看卡牌/技能│
    │    - 确定目标值  │
    └─────────────────┘
         │
         ▼
    ┌─────────────────┐
    │ 3. 应用难度修正  │
    │    - 区域特性    │
    │    - 技能加成    │
    │    - 资源消耗    │
    └─────────────────┘
         │
         ▼
    ┌─────────────────┐
    │ 4. 执行掷骰     │
    │    - 投掷1d6    │
    │    - 记录结果   │
    └─────────────────┘
         │
         ▼
    ┌─────────────────┐
    │ 5. 应用结果修正  │
    │    - 判定加成    │
    │    - 额外骰子    │
    └─────────────────┘
         │
         ▼
    ┌─────────────────┐
    │ 6. 计算最终结果  │
    │    - 比较点数    │
    │    - 确定成败    │
    └─────────────────┘
         │
         ▼
    ┌─────────────────┐
    │ 7. 执行判定效果  │
    │    - 成功效果    │
    │    - 失败效果    │
    └─────────────────┘
```

**判定成功条件**：
```
最终点数 = 骰子点数 + 判定加成 - 难度修正
判定成功：最终点数 ≥ 目标值
判定失败：最终点数 < 目标值

特殊情况：
- 大成功：骰子点数 = 6（可能触发额外效果）
- 大失败：骰子点数 = 1（可能触发负面效果）
```

**难度等级表**：

| 难度等级 | 目标值 | 基础成功率 | 适用场景 |
|:-------:|:------:|:---------:|:-------:|
| 极易 | 2 | 83.3% (5/6) | 简单任务、新手引导 |
| 简单 | 3 | 66.7% (4/6) | 基础操作、常规攻击 |
| 普通 | 4 | 50.0% (3/6) | 标准判定、一般技能 |
| 困难 | 5 | 33.3% (2/6) | 复杂操作、强力技能 |
| 极难 | 6 | 16.7% (1/6) | 极限挑战、特殊任务 |

**判定修正因素**：

| 修正类型 | 影响方式 | 示例 |
|:-------:|:-------:|:----:|
| 区域特性 | ±目标值 | AI控制区难度+1 |
| 技能加成 | +判定值 | "精准分析" +2判定 |
| 资源消耗 | ±目标值 | 消耗信息降低难度 |
| 状态效果 | ±判定值 | "增益状态" +1判定 |
| 装备加成 | +判定值 | 特殊装备加成 |

**判定类型详解**：

**1. 攻击判定**
- **触发时机**：使用攻击类卡牌时
- **目标值**：骰子判定结果，通常为1-6
- **成功效果**：攻击命中，造成伤害/移除标记
- **失败效果**：攻击未命中，无效果或部分效果
- **特殊规则**：某些攻击卡牌失败时仍有基础效果

**2. 防御判定**
- **触发时机**：使用防御类卡牌时
- **目标值**：骰子判定结果，通常为1-6
- **成功效果**：防御成功，完全格挡或减免伤害
- **失败效果**：防御失败，受到全额伤害
- **特殊规则**：某些防御卡牌失败时仍有基础效果

**3. 技能判定**
- **触发时机**：使用技能时
- **目标值**：骰子判定结果，通常为1-6
- **成功效果**：技能完全生效
- **失败效果**：技能不生效或部分生效
- **特殊规则**：部分技能有"即使失败也有效果"的设定

**4. 响应判定**
- **触发时机**：在响应阶段使用响应卡牌时
- **目标值**：骰子判定结果，通常为1-6
- **成功效果**：成功响应，打断或反制敌人行动
- **失败效果**：响应失败，敌人行动正常执行
- **特殊规则**：响应判定通常有时间限制

**判定策略建议**：

1. **风险评估**：在判定前评估失败的风险是否可接受
2. **资源投入**：考虑是否消耗资源提高判定成功率
3. **备用方案**：准备判定失败后的应对策略
4. **时机选择**：选择合适的时机进行关键判定
5. **概率计算**：了解不同难度的成功率，合理规划
│  极难    │    6     │  16.7% (1/6)   │
└──────────┴──────────┴────────────────┘
```

#### 判定修正

某些卡牌和技能可以影响判定结果：

| 修正类型 | 效果 | 示例 |
|:-------:|:----:|:----:|
| 判定加成 | 骰子结果+X | "精准分析" +2判定 |
| 额外骰子 | 投掷多个骰子取最高 | "双重验证" 投2个骰子 |
| 降低难度 | 目标值-X | "情报优势" 目标值-1 |
| 自动成功 | 无需判定直接成功 | "完美执行" |

#### 判定示例

**示例1：基础判定**
```
场景：玩家使用"入侵检测"卡牌
目标值：4
骰子结果：5
判定：5 ≥ 4，成功！
效果：移除目标区域1个攻击标记
```

**示例2：修正判定**
```
场景：玩家使用"深度分析"（目标值5，有+1判定加成）
骰子结果：4
修正后：4 + 1 = 5
判定：5 ≥ 5，成功！
效果：查看敌人手牌并弃置1张
```

**示例3：失败判定**
```
场景：敌人使用"鱼叉式钓鱼"（目标值4）
骰子结果：2
判定：2 < 4，失败！
效果：敌人技能不生效
```

#### 攻击类卡牌（ATK）

**编号前缀**：LV（敌人卡）、NI（情报攻击卡）

**特点**：用于攻击敌人、移除敌方标记

| 子类型 | 功能 | 示例卡牌 | 编号示例 |
|:------:|:----:|:-------:|:-------:|

**使用策略**：
- 优先在敌方标记密集区域使用
- 配合区域特性获得额外收益

#### 防御类卡牌（DEF）

**编号前缀**：NF（普通防御卡）、LI（关卡防御卡）

| 特殊防御 | 提供特殊保护 | 人工控制权、行为异常检测 | LI2-1T1 |

**使用策略**：
- 在安全等级较低时优先使用恢复类
- 在关键区域使用特殊防御建立优势
- 与攻击卡牌配合使用，攻守兼备

#### 策略类卡牌（TAC）

- 在游戏早期使用资源策略建立优势
- 在敌人强势时使用控制策略反制
- 信息策略可以帮助预判敌人行动

#### 判定类卡牌（JUD）

**编号前缀**：NJ（判定卡）

判定类卡牌是特殊的策略卡牌，使用时需要进行骰子判定来决定效果。分为即时判定和非即时判定两种类型。

**即时判定卡牌**

即时判定在使用时立即进行判定，根据结果立即生效。

| 子类型 | 功能 | 判定目标值 | 成功效果 | 失败效果 | 示例卡牌 |
|:------:|:----:|:---------:|:-------:|:-------:|:-------:|
| 攻击判定 | 增强攻击效果 | 4-5 | 攻击命中，附加额外伤害 | 攻击未命中或伤害减半 | 精准打击、致命一击 |
| 防御判定 | 增强防御效果 | 3-4 | 完全格挡或大幅减伤 | 格挡失败，受到全额伤害 | 完美防御、紧急回避 |
| 技能判定 | 触发特殊技能 | 4-6 | 技能完全生效 | 技能不生效或部分生效 | 深度分析、快速破解 |

**非即时判定卡牌**

非即时判定在使用时不立即判定，而是在特定时机（如敌人行动时、回合结束时）进行判定。

| 子类型 | 功能 | 判定时机 | 判定目标值 | 效果 | 示例卡牌 |
|:------:|:----:|:-------:|:---------:|:----:|:-------:|
| 陷阱判定 | 设置陷阱 | 敌人触发时 | 4 | 敌人触发陷阱时进行判定，成功则陷阱生效 | 陷阱布置、伏击准备 |
| 持续判定 | 持续效果 | 每回合结束时 | 3-5 | 每回合结束时判定，成功则效果持续 | 持续监控、长期防护 |
| 响应判定 | 响应触发 | 特定条件满足时 | 4-5 | 条件满足时自动判定，成功则触发效果 | 自动反击、智能防御 |

**判定类卡牌使用策略**

1. **风险评估**：在使用判定类卡牌前，评估判定失败的风险是否可接受
2. **资源投入**：考虑是否消耗额外资源（如信息）来提高判定成功率
3. **时机选择**：
   - 即时判定：在需要立即见效时使用
   - 非即时判定：在预判敌人行动或需要持续效果时使用
4. **概率计算**：了解不同目标值的成功率，合理规划
   - 目标值3：成功率66.7%
   - 目标值4：成功率50.0%
   - 目标值5：成功率33.3%
   - 目标值6：成功率16.7%

### 3.3 卡牌资源消耗

#### 资源需求说明

每张卡牌都有资源需求，格式为：
```
[行动点] + [算力/资金/信息]

示例：
- 入侵检测：2行动点 + 1算力
- 系统修复：3行动点 + 1资金
- 行为分析：2行动点 + 1信息
```

#### 资源消耗表

| 卡牌类型 | 平均行动点 | 平均资源消耗 | 资源类型偏好 |
|:-------:|:---------:|:-----------:|:-----------:|

| 特殊攻击 | 3 | 2算力/信息 | 算力+信息 |
| 基础防御 | 2 | 1算力/资金 | 算力/资金 |
| 恢复类 | 3 | 1资金 | 资金 |
| 策略类 | 2 | 1信息 | 信息 |

#### 资源不足处理

当资源不足时：
1. **提示信息**：显示"资源不足，无法使用"
2. **替代方案**：建议使用其他卡牌
3. **资源获取**：提示可以通过哪些方式获取资源

#### 资源管理建议

**早期游戏（1-3回合）**
- 优先使用低消耗卡牌
- 积累资源，不要过早消耗
- 建立基础防御

**中期游戏（4-8回合）**
- 开始使用中等消耗卡牌
- 根据局势灵活调整
- 保持资源在50%以上

**后期游戏（9+回合）**
- 可以使用高消耗强力卡牌
- 全力进攻或防守
- 注意回合限制

## 四、区域控制机制

### 4.1 标记放置规则

#### 基础放置规则

```
┌─────────────────────────────────────────────────────────────┐
│                      标记放置规则                            │
└─────────────────────────────────────────────────────────────┘

放置条件：
1. 玩家必须位于目标区域
2. 必须有足够的行动点
3. 必须满足区域特性要求

消耗计算：
基础消耗：1行动点/个
修正计算：基础消耗 + 区域修正 + 技能修正

示例：
- 基础放置：1行动点
- 在人类控制区：1 - 1 = 0行动点（免费）
- 在通讯中继站：1 + 1 = 2行动点
```

#### 放置限制

| 限制类型 | 说明 | 影响 |
|:-------:|:----:|:----:|
| 行动点限制 | 行动点不足时无法放置 | 无法放置 |
| 区域限制 | 某些区域有放置上限 | 达到上限后无法放置 |
| 技能限制 | 敌人技能可能阻止放置 | 放置失败 |
| 状态限制 | 特定状态下无法放置 | 需要解除状态 |

#### 放置策略

**优先级策略**
```
高优先级：
1. 敌方标记密集区域
2. 关键设施区域
3. 友方劣势区域

中优先级：
4. 中立区域
5. 有战略价值的区域

低优先级：
6. 已控制区域
7. 边缘区域
```

**时机策略**
- **早期**：分散放置，建立存在感
- **中期**：集中优势，控制关键区域
- **后期**：全力防守或进攻

### 4.3 区域控制判定

#### 控制判定规则

```
控制判定公式：
友方控制 = 友方标记数 > 敌方标记数
敌方控制 = 敌方标记数 > 友方标记数
中立状态 = 友方标记数 = 敌方标记数

控制优势度 = |友方标记数 - 敌方标记数|
优势度越大，控制越稳固
```

#### 控制奖励

| 控制状态 | 奖励效果 | 触发条件 |
|:-------:|:-------:|:-------:|
| 完全控制 | 每回合额外1行动点 | 优势度≥3 |
| 稳固控制 | 敌方技能效果-1 | 优势度≥2 |
| 基础控制 | 无额外奖励 | 优势度=1 |
| 争夺中 | 无奖励，可能触发战斗 | 优势度=0 |

#### 区域控制战术

**速攻战术**
```
目标：快速控制关键区域
步骤：
1. 集中行动点在一个区域
2. 快速建立标记优势
3. 获得控制奖励
4. 利用奖励扩大优势
```

**均衡战术**
```
目标：稳定控制多个区域
步骤：
1. 在每个区域放置适量标记
2. 保持各区域优势度≥1
3. 根据敌人动向调整
4. 避免单点突破
```

**重点防御战术**
```
目标：保护关键区域
步骤：
1. 识别最重要的1-2个区域
2. 在这些区域建立强防御
3. 允许边缘区域失守
4. 利用核心区域反击
```

- 优点：减少直接威胁

选项B：清理传播路径（防止扩散）
- 优点：阻止敌人扩张
- 缺点：隔离区压力大

推荐：选项B，优先阻止扩散
```

**决策点2：何时使用强力卡牌？**
```
建议：
- 早期（1-3回合）：保留强力卡牌
- 中期（4-6回合）：根据局势使用
- 后期（7+回合）：全力使用

2. 保持安全等级在安全线以上

### 6.3 通用策略指导

#### 资源管理策略

**算力管理黄金法则**
```
1. 始终保持至少2点算力储备
2. 优先使用算力需求低的卡牌
3. 在关键时刻使用高算力卡牌
4. 利用卡牌效果生成额外算力
```

**资金管理策略**
```
1. 资金用于紧急恢复和关键卡牌
2. 不要过早耗尽资金
3. 利用"资源调配"等卡牌优化资金
4. 在安全等级低时优先使用恢复类卡牌
```

**信息管理策略**
```
1. 信息是最稀缺的资源，谨慎使用
2. 优先用于提高判定成功率
3. 在关键判定前使用信息加成
4. 利用"情报收集"等卡牌补充信息
```

#### 卡牌使用策略

**卡牌保留原则**
```
必留卡牌：
- 强力攻击卡（应对紧急情况）
- 恢复类卡牌（安全等级低时使用）
- 特殊克制卡牌（针对特定敌人）

可弃卡牌：
- 低效果卡牌（资源紧张时）
- 重复类型卡牌（保留1张即可）
- 当前局势无用的卡牌
```

**卡牌组合原则**
```
高效组合：
1. 判定+攻击：提高攻击成功率
2. 侦察+针对性：了解敌人后精准打击
3. 防御+恢复：建立稳固防线
4. 控制+爆发：限制敌人后全力输出

避免组合：
1. 同类型卡牌连续使用（资源浪费）
2. 效果冲突的卡牌（互相抵消）
3. 资源需求过高的组合（无法执行）
```

#### 区域控制策略

**区域优先级矩阵**
```
                高战略价值    低战略价值
高敌方威胁      最高优先级    高优先级
低敌方威胁      中优先级      低优先级

解释：
- 最高优先级：立即处理，投入最多资源
- 高优先级：尽快处理，防止恶化
- 中优先级：适时处理，保持关注
- 低优先级：最后处理，可暂时放弃
```

**动态调整策略**
```
根据局势调整：

优势时：
- 扩大优势区域
- 压缩敌人空间
- 准备最终攻击

劣势时：
- 收缩防线
- 保护关键区域
- 寻找反击机会

均衡时：
- 寻找突破口
- 制造局部优势
- 逐步积累优势
```

**防御方（蓝方）**
- **目标**：保护系统安全，维持安全等级，阻止敌人渗透
- **资源**：算力、资金、信息
- **核心指标**：安全等级（初始根据关卡设置而变动）
- **科技树绑定**：
  - 安全等级 5：解锁T1科技，获得基础防御卡牌和效果
  - 安全等级 15：解锁T2科技，获得进阶防御卡牌和效果

- **资源**：算力、资金、信息

- **科技树绑定**：
  - 渗透等级 5：解锁T1科技，获得基础攻击卡牌和效果
  - 渗透等级 15：解锁T2科技，获得进阶攻击卡牌和效果
  - 渗透等级 30：解锁T3科技，获得高级攻击卡牌和效果
  - 渗透等级 40：解锁T4科技，获得专家级攻击卡牌和效果
  - 渗透等级 50：解锁T5科技，获得大师级攻击卡牌和效果
- **肉鸽选择**：T1-T4解锁时会触发肉鸽选择（3选1）
- **优势**：后手反击、可以使用攻击类卡牌、攻击成功增加渗透等级

| **防御侧翼** | 放置防御标记消耗-1 | 放置攻击标记消耗+1 | 防御方控制时安全等级+5 |
| **攻击侧翼** | 放置防御标记消耗+1 | 放置攻击标记消耗-1 | 攻击方控制时渗透等级+5 |

#### 区域控制机制

**控制判定**：
- 当某区域友方标记数 > 敌方标记数时，控制该区域
- 控制效果在回合开始时生效

**核心区域特殊规则**：
- 核心区域的控制权直接影响安全等级/渗透等级
- 每控制核心区域1个回合：控制方等级±10
- 核心区域失守时，防御方安全等级大幅下降

**移动规则**：
- 玩家可以在行动阶段移动到其他区域
- 移动消耗：1行动点
- 中央通道可以自由移动，不消耗额外行动点

### 7.5 对战模式策略

#### 防御方策略

**早期策略（1-3轮次）**
```
目标：建立基础防线

执行：
1. 在核心区域放置标记
2. 使用低消耗防御卡
3. 观察攻击方卡组类型
4. 保留关键防御卡

注意：
- 不要过早暴露全部防御手段
- 注意保存资源应对后期
```

**中期策略（4-7轮次）**
```
目标：稳固防守，寻找反击机会

执行：
1. 扩展防守范围到多个区域
2. 使用"追踪反制"了解对方手牌
3. 在安全等级下降时使用恢复卡
4. 建立标记优势后适当反击

关键决策：
- 何时使用"完美防御"
- 是否冒险反击
```

**后期策略（8+轮次）**
```
目标：守住优势直到胜利

执行：
1. 全力防守核心区域
2. 使用所有保留的强力卡牌
3. 计算安全等级，确保不低于50
4. 必要时使用"战术撤退"

注意：
- 时间压力下的决策
- 防止攻击方的终极技能
```

#### 攻击方策略

**早期策略（1-3轮次）**
```
目标：快速建立渗透基础

执行：
1. 使用"快速渗透"增加渗透等级
2. 在多个区域分散放置标记
3. 测试防御方的响应能力
4. 保留强力攻击卡

关键：
- 快速累积渗透等级
- 不要让防御方建立稳固防线
```

**中期策略（4-7轮次）**
```
目标：突破防线，扩大优势

执行：
1. 使用"多点突破"分散防御
2. 使用"伪装攻击"绕过防御
3. 集中攻击防御薄弱的区域
4. 在安全等级低时全力进攻

时机把握：
- 防御方资源耗尽时猛攻
- 防御方手牌少时强攻
```

**后期策略（8+轮次）**
```
目标：完成渗透或降低安全等级至0

执行：
1. 使用"终极入侵"全面进攻
2. 集中所有资源进行最后一击
3. 必要时牺牲渗透等级换取安全等级下降
4. 使用时间加速确保操作完成

决胜时刻：
- 计算是否能在回合结束前达成胜利条件
- 判断是否需要进行最后一搏
```

### 7.7 对战模式技巧

#### 通用技巧

1. **心理博弈**
   - 观察对手的行动模式
   - 适时虚张声势或隐藏实力
   - 利用时间压力影响对手决策

2. **资源管理**
   - 计算双方的资源消耗
   - 在资源领先时主动进攻
   - 资源落后时保守防守

3. **信息收集**
   - 通过"情报交换"了解对手
   - 分析对手已使用的卡牌
   - 预测对手的手牌和策略

4. **时机把握**
   - 识别关键的决胜回合
   - 在对手弱势时猛攻
   - 保留反击手段应对突发情况

#### 常见错误

| 错误 | 说明 | 改进建议 |
|:----:|:----:|:-------:|
| 过早暴露 | 早期使用全部强力卡牌 | 保留关键卡到后期 |
| 资源浪费 | 在不必要的地方消耗资源 | 精打细算，计划使用 |
| 忽视防守 | 攻击方只攻不守 | 注意防御，防止被反击 |
| 保守过度 | 防御方完全不反击 | 适时反击，掌握主动 |
| 时间失控 | 思考时间过长导致操作 incomplete | 提前规划，快速决策 |

## 附录：快速参考卡

### 回合流程速查

```
关卡模式：
判定→恢复→摸牌→行动→响应→弃牌→结束
（每角色依次执行，4角色=1轮次）

对战模式：
防御方：判定→恢复→摸牌→行动→响应→弃牌→结束
攻击方：判定→恢复→摸牌→行动→响应→弃牌→结束
（2角色=1轮次）
```

### 资源速查

| 资源 | 图标 | 主要用途 | 恢复方式 |
|:----:|:----:|:-------:|:-------:|
| 算力 | ⚡ | 技术操作 | 每回合+1 |
| 资金 | 💰 | 购买/恢复 | 每回合+1 |
| 信息 | 📊 | 判定加成 | 每回合+1 |
| 安全等级 | 🛡️ | 科技树、胜负条件 | 特定卡牌 |
| 渗透等级 | 🔴 | 科技树、胜负条件 | 敌人攻击增加 |

### 判定速查

```
判定成功：最终点数 ≥ 目标值
最终点数 = 骰子点数 + 判定加成 - 难度修正

难度：极易(2) 简单(3) 普通(4) 困难(5) 极难(6)
修正：+判定值 / 额外骰子 / 降低难度
特殊：骰子=6大成功，骰子=1大失败
```

### 卡牌编号速查

```
格式：[前缀][关卡]-[序号][科技等级]

前缀：NF=防御 NI=情报 NE=事件 LI=关卡 LV=敌人 S=特殊
关卡：0=通用 1-9=对应关卡
科技：T1=基础 T2=进阶 T3=高级

示例：LI2-1T1 = 关卡2情报卡1号，科技等级1
```

|:----:|:-------:|

| 渗透等级高 | 快速清理敌方标记 |
| 敌方标记多 | 使用范围攻击卡牌 |
| 资源不足 | 使用资源生成卡牌 |
| 敌人技能强 | 使用克制类卡牌 |
