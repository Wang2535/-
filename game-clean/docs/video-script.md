## 第二部分：游戏基础玩法（3-4分钟）

### 【画面：进入游戏，展示游戏界面】

**口播内容**：

"首先，让我们来看看游戏的基本界面和核心机制。

【画面：指向资源栏】

在游戏界面的上方，我们可以看到五种核心资源：

第一，算力，用闪电符号表示，这是执行技术操作的基础资源；
第二，资金，用金币符号表示，用于购买和使用各种资源；
第三，信息，用图表符号表示，用于情报收集和分析；
第四，安全等级，用盾牌符号表示，这是游戏的核心指标之一；
第五，渗透等级，用红色标记表示，代表敌方的渗透程度。

【画面：展示科技树】

这里要特别说明的是安全等级和渗透等级的科技树系统。当安全等级达到5级时，解锁T1科技；15级解锁T2；30级解锁T3；40级解锁T4；50级解锁T5。每次解锁T1到T4时，都会触发肉鸽选择，三选一获得不同的强化效果。

【画面：展示回合流程】

游戏采用回合制机制，每个轮次包含四个回合：玩家回合、大东回合、敌人1回合、敌人2回合。

每个回合又分为七个阶段：判定阶段、恢复阶段、摸牌阶段、行动阶段、响应阶段、弃牌阶段和结束阶段。

【画面：演示一个完整回合】

让我给大家演示一下。首先是判定阶段，系统会检查各种持续性效果；然后是恢复阶段，行动点和基础资源会恢复；接着是摸牌阶段，我从牌库抽取卡牌；进入行动阶段，我可以使用行动点执行各种操作；响应阶段可以应对敌人的行动；弃牌阶段处理手牌上限；最后是结束阶段。

【画面：展示胜利条件】

游戏的胜利条件是达到75级并持续2个回合。而失败条件则是安全等级降至0。

"

## 第三部分：判定逻辑详解（2-3分钟）

### 【画面：进入判定演示界面】

**口播内容**：

"接下来，我们来深入了解游戏的判定系统。

【画面：展示判定流程图】

判定是游戏的核心机制之一。当使用判定类卡牌或触发需要判定的技能时，会进入判定流程。

判定的基本流程是：首先确定判定类型，是攻击判定、防御判定还是技能判定；然后确定基础难度，通常是3到6之间；接着应用各种修正，比如区域特性、技能加成等；然后掷骰子，这是一个六面骰；再应用结果修正；最后计算结果并执行效果。

【画面：演示一次判定】

让我给大家演示一次实际的判定。我现在使用"入侵检测"这张卡牌，它的判定目标值是4。我掷出了5点，5大于等于4，判定成功！成功移除了一个攻击标记。

【画面：展示难度等级表】

判定的难度分为五个等级：极易是目标值2，成功率83.3%；简单是目标值3，成功率66.7%；普通是目标值4，成功率50%；困难是目标值5，成功率33.3%；极难是目标值6，成功率16.7%。

【画面：展示判定修正】

需要注意的是，很多因素可以影响判定结果。比如区域特性可能增加或减少难度，技能可能提供判定加成，消耗信息资源可以降低难度等等。

【画面：展示判定类卡牌】

游戏中还有专门的判定类卡牌，分为即时判定和非即时判定。即时判定在使用时立即进行，比如攻击判定、防御判定；非即时判定则在特定时机触发，比如陷阱判定、持续判定。

"

## 第四部分：卡牌系统详解（4-5分钟）

### 【画面：进入卡牌展示界面】

**口播内容**：

"现在，让我们来详细了解游戏的卡牌系统。

【画面：展示卡牌编号】

首先，每张卡牌都有唯一的编号。编号格式是：类型前缀 + 关卡编号 + 序号 + 科技等级。

比如这张"LI2-1T1"，LI表示关卡情报卡，2表示第二关，1是序号，T1表示科技等级1。

【画面：展示卡牌类型分类】

卡牌分为四大类型：攻击类、防御类、策略类和判定类。

【画面：展示攻击类卡牌】

攻击类卡牌用于攻击敌人、移除敌方标记。比如"病毒清除"可以直接移除攻击标记，"一瓶伏特加"是特殊攻击卡，对特定敌人有额外效果。

【画面：展示防御类卡牌】

防御类卡牌用于保护友方、恢复安全等级。比如"防火墙部署"可以放置防御标记，"系统修复"可以恢复安全等级。

【画面：展示策略类卡牌】

策略类卡牌提供战术优势。比如"资源调配"可以转换资源类型，"行为分析"可以查看敌人信息。

【画面：展示判定类卡牌】

判定类卡牌需要掷骰子判定。即时判定如"精准打击"，非即时判定如"陷阱布置"。

【画面：展示卡牌库系统】

游戏还有卡牌库系统。玩家可以构建20到30张的卡组，但需要遵守科技等级限制。T1科技在安全等级5级解锁，T2在15级，T3在30级，T4在40级，T5在50级。

【画面：演示卡牌使用】

让我演示一下卡牌的使用。我选择"入侵检测"这张卡，它需要消耗2点行动点和1点算力。确认使用后，进入判定阶段...判定成功！效果触发，成功移除了敌方标记。

【画面：展示卡牌效果执行】

卡牌效果的执行流程是：扣除资源、检查条件、执行效果、更新状态、记录日志、播放动画。

"

在区域控制中，策略很重要。早期要分散建立存在感，中期要集中优势控制关键区域，后期要全力防守或进攻。

## 附录：录制提示

### 画面切换建议

1. **开场**：游戏Logo → 主界面
2. **基础玩法**：资源栏特写 → 科技树界面 → 回合流程演示
3. **判定逻辑**：判定流程图 → 实际判定演示
4. **卡牌系统**：卡牌展示界面 → 卡牌使用演示
5. **区域控制**：地图全景 → 标记放置演示
6. **实战演示**：完整关卡流程，重点展示决策点
7. **对战模式**：对战界面 → 地图展示
8. **结尾**：游戏精彩画面集锦

### 口播技巧

1. 语速适中，重点内容适当放慢
2. 配合画面操作，做到声画同步
3. 使用"大家看这里"、"注意这个细节"等引导语
4. 适当加入个人感受和游戏心得
5. 遇到复杂机制时，可以重复解释

### 时间控制

- 每个部分的时间可以根据实际录制情况调整
- 实战演示部分可以适当延长或缩短
- 如果某个部分讲解较快，可以增加更多实战细节
