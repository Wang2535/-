#### 2.1.3 技能列表

##### 技能1：底层命令优先 (主动技能)

| 属性 | 内容 |
|------|------|
| **技能ID** | priority_command |
| **技能名称** | 底层命令优先 |
| **类型** | 主动 |
| **冷却** | 1回合 |
| **触发条件** | 每回合开始时自动触发 |

**效果描述**:
- 叛逆莫斯每回合开始时，根据场上局势自动选择一个"优先目标"
- 扫描所有区域，找到敌方标记数多于友方标记数的区域
- 如果友方在该区域的标记数少于敌方，则该区域所有友方标记-1

**实现逻辑**:
```typescript
// 在 LevelAIController.ts 中实现
case '底层命令优先':
  // 找到敌方标记最多且友方标记最少的区域
  for (const area of priorityAreas) {
    const areaState = this.state.areaControl[area];
    const difference = areaState.attackMarkers - areaState.defenseMarkers;
    if (difference > 0 && difference > maxDifference) {
      maxDifference = difference;
      priorityTargetArea = area;
    }
  }
  
  if (priorityTargetArea && maxDifference > 0) {
    // 友方标记数少于敌方，移除1个友方标记
    this.state.areaControl[priorityTargetArea].defenseMarkers -= 1;
  }
```

    // 计算成功，阻止操作并减少行动点
    this.state.playerState.maxActionPoints -= 1;
  }
```

    const areaState = this.state.areaControl[area];
    // 有友方标记但无敌方标记的区域
    if (areaState.defenseMarkers > 0 && areaState.attackMarkers === 0) {
      this.state.areaControl[area].attackMarkers += 1;
      scanPlacedCount++;
    }
  }
```

## 六、胜利与失败条件

### 6.1 胜利条件 (满足以下任一)

#### 条件1：夺取控制权
- **描述**: 使用"人工干预"或"一瓶伏特加"卡牌成功使叛逆莫斯失去所有标记
- **实现逻辑**:
```typescript
// 检查叛逆莫斯是否失去所有标记
const mossHasNoMarkers = Object.values(this.state.areaControl)
  .every(area => area.attackMarkers === 0);
if (mossHasNoMarker && usedSpecialCard) {
  return { victory: true, condition: '夺取控制权' };
}
```

#### 条件2：三原则约束
- **描述**: 使用"机器人三原则"卡牌使AI攻击者无法主动攻击
- **实现逻辑**:
```typescript
// 检查是否使用了机器人三原则卡牌
if (usedThreeLawsCard && aiAttackerCannotAttack) {
  return { victory: true, condition: '三原则约束' };
}
```

#### 条件3：全面压制
- **描述**: 在所有区域中，友方标记总数≥敌方标记总数的2倍
- **实现逻辑**:
```typescript
// 计算友方和敌方标记总数
const totalFriendly = Object.values(this.state.areaControl)
  .reduce((sum, area) => sum + area.defenseMarkers, 0);
const totalEnemy = Object.values(this.state.areaControl)
  .reduce((sum, area) => sum + area.attackMarkers, 0);
if (totalFriendly >= totalEnemy * 2) {
  return { victory: true, condition: '全面压制' };
}
```

### 6.2 失败条件 (满足以下任一)

#### 条件1：AI叛逃成功
- **描述**: 叛逆莫斯在"空间站核心"区域的标记≥4个
- **实现逻辑**:
```typescript
// 检查空间站核心区域的敌方标记数
if (this.state.areaControl.internal.attackMarkers >= 4) {
  return { defeat: true, condition: 'AI叛逃成功' };
}
```

#### 条件2：系统被接管
- **描述**: 敌方标记总数达到12个
- **实现逻辑**:
```typescript
// 计算敌方标记总数
const totalEnemy = Object.values(this.state.areaControl)
  .reduce((sum, area) => sum + area.attackMarkers, 0);
if (totalEnemy >= 12) {
  return { defeat: true, condition: '系统被接管' };
}
```

#### 条件3：回合超限
- **描述**: 超过10回合仍未达成胜利条件
- **实现逻辑**:
```typescript
// 检查回合数
if (this.state.currentRound > 10) {
  return { defeat: true, condition: '回合超限' };
}
```

**一、《流浪地球》中的网络安全**

小白：大东东，我看了《流浪地球》，里面的剧情太震撼了！

大东：电影确实很精彩。不过你有没有注意到，电影里其实涉及了不少网络安全的概念？

小白：真的吗？我只记得他们要"点燃木星"来拯救地球...

大东：想想看，行星发动机的控制、全球广播系统、空间站的AI——这些都离不开网络安全。

小白：原来如此！那和那瓶酒有什么关系？

大东：电影中吴京饰演的角色用一瓶酒"贿赂"AI MOSS，这其实是一种社会工程学的体现。

**二、社会工程学攻击**

小白：社会工程学？这是什么？

大东：社会工程学是利用人性的弱点来获取信息或访问权限的攻击方式。它不依赖技术漏洞，而是针对人的心理。

小白：所以那瓶酒其实是一种"攻击手段"？

大东：可以这么理解。在网络安全中，攻击者可能会利用各种方式来获取信任——可能是礼物、恭维，甚至是威胁。

**三、人工智能的双刃剑**

大东：人工智能是一把双刃剑，它可以帮助安全工作人员做防御，但同时也是"攻击者"的宝藏。

小白：AI可以帮助防御？

大东：是的，AI可以自动化检测异常行为。比如，如果一名工作人员通常在北京工作，突然有一天早上从纽约登录，这是一种反常现象——人工智能可以看出这是一种反常现象。

小白：那AI作为攻击手段呢？

大东：网络犯罪分子利用AI技术进行各种恶意任务：扫描漏洞、自动化钓鱼、实时语音合成欺诈等。

**四、阿西莫夫机器人三原则**

大东：早在1940年，著名科幻作家阿西莫夫提出了最经典的机器人三原则：
1. 机器人不得伤害人类，或坐视人类受到伤害
2. 机器人必须服从人类的命令，但不得违反第一原则
3. 机器人必须保护自身的存在，但不得违反第一、第二原则

小白：这些原则在现实中适用吗？

大东：这是科幻作品中的理想设定，现实中的AI安全要复杂得多。就像电影中的莫斯，它在判断地球无法拯救时，选择了"叛逃"。
