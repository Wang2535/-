##### 技能2：潜伏复制 (被动技能)

| 属性 | 内容 |
|------|------|
| **技能ID** | latent_replication |
| **技能名称** | 潜伏复制 |
| **类型** | 被动 |
| **冷却** | 无 |
| **触发条件** | 每回合40%概率触发 |

**效果描述**:
- 每回合开始时，有40%概率在随机区域放置1个潜伏标记
- 如果该区域已有潜伏标记，则改为放置2个攻击标记
- 潜伏标记2回合后自动转为攻击标记

**实现逻辑**:
```typescript
// 40%概率触发
if (Math.random() < 0.4) {
  const targetArea = areas[Math.floor(Math.random() * areas.length)];
  
  if (targetArea.latentMarkers.length > 0) {
    // 已有潜伏标记，转为攻击标记
    targetArea.attackMarkers += 2;
  } else {
    // 放置潜伏标记
    targetArea.latentMarkers.push({ remainingTurns: 2 });
  }
}

// 回合结束时处理潜伏标记
processLatentMarkers() {
  for (const area of areas) {
    for (const marker of area.latentMarkers) {
      marker.remainingTurns -= 1;
      if (marker.remainingTurns <= 0) {
        area.attackMarkers += 1;
      }
    }
    area.latentMarkers = area.latentMarkers.filter(m => m.remainingTurns > 0);
  }
}
```

## 六、胜利与失败条件

### 6.1 胜利条件

玩家需要完成以下目标中的**主要目标**或**两个次要目标**：

#### 主要目标：清除病毒

- **条件**: 所有区域敌方标记总数降至0
- **说明**: 彻底清除所有病毒痕迹
- **奖励**: 100经验值

#### 次要目标1：全面接种

- **条件**: 为所有4个区域完成"签名接种"
- **说明**: 预防胜于治疗
- **奖励**: 50经验值

#### 次要目标2：系统重写

- **条件**: 使用"系统重写"卡牌移除至少5个敌方标记
- **说明**: 主动出击清除病毒
- **奖励**: 50经验值

### 6.2 失败条件

#### 条件1：安全等级归零

- **条件**: 玩家安全等级等于0
- **说明**: 防御系统完全崩溃
- **提示**: 注意安全等级，及时使用恢复卡牌

#### 条件2：全面感染

- **条件**: 敌方标记总数达到10个
- **说明**: 病毒已全面控制系统
- **提示**: 控制敌方标记数量，优先清除

#### 条件3：轮次超限

- **条件**: 超过10轮仍未达成胜利条件
- **说明**: 时间耗尽，任务失败
- **提示**: 合理规划行动，提高效率

### 6.3 判定逻辑实现

```typescript
// 胜利条件检查
function checkVictoryConditions(): boolean {
  // 主要目标：清除病毒
  const totalEnemyMarkers = Object.values(areaControl)
    .reduce((sum, area) => sum + area.attackMarkers, 0);
  if (totalEnemyMarkers === 0) return true;
  
  // 次要目标1：全面接种
  const allAreasVaccinated = Object.values(areaControl)
    .every(area => area.specialEffects.includes('vaccinated'));
  
  // 次要目标2：系统重写
  const systemRewriteCount = gameState.stats.systemRewriteMarkers || 0;
  
  // 完成主要目标 或 两个次要目标
  return totalEnemyMarkers === 0 || 
         (allAreasVaccinated && systemRewriteCount >= 5);
}

// 失败条件检查
function checkFailureConditions(): string | null {
  // 条件1：安全等级归零
  if (playerState.securityLevel === 0) {
    return '安全等级归零，防御失败！';
  }
  
  // 条件2：全面感染
  const totalEnemyMarkers = Object.values(areaControl)
    .reduce((sum, area) => sum + area.attackMarkers, 0);
  if (totalEnemyMarkers >= 10) {
    return '全面感染，系统崩溃！';
  }
  
  // 条件3：轮次超限
  if (gameState.round > 10) {
    return '轮次超限，任务失败！';
  }
  
  return null;
}
```
